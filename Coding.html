Promotion Macro

The Promotion Macro turns a vendor’s Navy Deal Offer Form (DOF) into a ready-to-key START promotion template in one click. When you click Export Promotion it:

  1. Builds the START promotion template rows (item, zone, fixed price, retail, comments).
  2. Logs the promotion to the brand’s tab in the Buyer Promo Tracker and checks for overlapping promotions.
  3. Optionally loads the items into the Fact Tags workbook for sale signs.
  4. Saves the template to the shared promotions folder, split into one file per month for long promotions.
  5. Drafts the Outlook email to the right team with the file attached, ready for you to review and send.

Promotion Macro (2026)

Buyer Promo Tracker 2026

Save both workbooks to a shared path your team can access. The macro opens the START template, the tracker and the Fact Tags workbook from the paths in its CONFIGURATION section, so update those paths to your team’s folders first (see Assign Tracker Path).

Before You Run It

  • Brand tab exists in the tracker. The tracker must have a tab named exactly like the vendor/brand name you enter in the macro (e.g. MSI). See Brand Tabbing.
  • Paths are set. The START template, tracker and Fact Tags file locations set in the macro point to files you can open.
  • Outlook is installed and signed in, so the macro can draft the email.
  • Close the tracker on other computers if possible. The macro saves it, and a copy someone else has open will be read-only.

The macro then runs on its own. Here’s what happens, in order:

  1. Builds the template. Opens the START promotion template and fills one row per item.
  2. Logs to the tracker. Opens the Buyer Promo Tracker, finds the tab named after the brand, adds the rows under the last entry with the promo dates, scanback $ and the Sent to START answer, then saves the tracker.
  3. Checks for overlaps. The tracker’s Overlap Check column (C) flags any item already on promotion for those dates. If any row says Overlap, you’ll see “Overlap Detected! Check Tracker.” and the macro stops: no file is saved and no email is drafted.
  4. Loads Fact Tags (if you said Yes).
  5. Saves the file(s). The file is named m.d.yy-m.d.yy Brand Month Promotion.xlsx, e.g. 3.1.26-3.31.26 MSI March Promotion.xlsx. Missing brand/month folders are created automatically.
  6. Drafts the email (if sending now) and shows “Process Complete.”
Long promotions are split by month. If the promotion runs longer than 31 days, the macro creates one file (and one email) per calendar month. Example: 3/15/26–5/10/26 produces 3.15.26-3.31.26 … March, 4.1.26-4.30.26 … April and 5.1.26-5.10.26 … May.
If an overlap is detected: the new rows have already been added to the tracker (that’s how the overlap was found). Look at the brand tab, fix the dates or items, delete the rows the macro just added, then run the macro again.

Fact Tags

Regular Fact Tags (Category Tabs)

Regular fact tags are the everyday shelf signs for items on display. Each category (Apple, Audio, Cameras, Computers, TV-Video, etc.) has its own tab where its tags are kept, plus an Email Fact Tags button that sends that category’s tags to the sign team. The Master tab combines all the categories so the SALE MASTER can find any item by RIN.

The workflow is: add the tag on its category tab → click Email Fact Tags → click Update Master.

Regular Tags Step 3: Click Update Master

After adding or changing tags, go to the Master tab and click Update Master (the same button is on Clearance Master). Do this before building sale signs, or new items will show #N/A on the SALE MASTER.

StepWhat Update Master does
1. Clears the Master tabRemoves everything below the header. Master is rebuilt from scratch each time, so never type on it.
2. Combines the category tabsCopies rows 6 down (columns A–M) from Apple, Audio, Computers, Cameras, Mobile Electronics, Smart Home, TV-Video, Video Games, Majors, ASOS and Small Appliances.

6. Locks the tabRe-protects Master (sorting and filtering still allowed) and shows a dad joke to confirm it finished.

To include them, add those two tab names to the list of tabs in the Update Master macro (VBA editor, QuickConsolidateAndSort).

Sale Fact Tags (SALE MASTER)

The SALE MASTER tab turns a list of RINs and sale prices into a sale-sign file for the sign team. You load the items, check that every item has a fact tag, then click EXPORT TO SIGN TEAM. The macro builds the sign-team file, removes items with no fact tag, names the file the way the sign team requires, and drafts the email.

Items with #N/A are dropped from the file without a warning. Check the list before exporting so an item that needs a sign isn’t missed. The sign team will not accept templates with #N/A items.

Ad Planner & DB Uploader

The NEX Ad Planner workbook covers an ad from start to finish:

  1. Measure past ads. Import QuantaSense sales data and calculate how much each item’s sales rose (its lift) in the weeks it was advertised.
  2. Plan the next ad. Build the week’s item list, pull item details from RMS, and export the lineup to the marketing PowerPoint template.
  3. Upload to the Ad Database. The export also fills the Ad Database Import sheet, which you send to the Ad Database with the Update Ad Database form (Ctrl+A).

NEX Ad Planner (v22)

Before You Start

How lift is measured

Baseline = the item’s normal, un-promoted sales. For each item, the Baseline Avg/Wk is the average weekly units it sold over the last 26 weeks excluding ad weeks. That answers “what does this item sell when we don’t advertise it?”, which is the right comparison, rather than a calendar-year average.

  • Unit Lift = ad week units − baseline: the extra units the ad drove.
  • Lift % = unit lift ÷ baseline: the headline number for one item.
  • Weighted Lift % (Lift Query) = total unit lift ÷ total baseline units across a group of items.
When you’re quoting…Use
One itemIts Lift % on the Ad Summary.
A vendor, product line or whole adThe Weighted Lift % from the Lift Query. It counts every unit equally, so it matches the actual extra units the ad drove.
A simple average of several items’ Lift %Don’t. Small items with big percentages inflate it.

Induction Checker (Item Validation Tool)

The Induction Checker is an Excel pre-check for RMS item induction workbooks, the templates used to create new item families, add GTINs and sizes, and attach suppliers in Oracle RMS. One run reviews every row on the Item tab and the Location tab, and catches the mistakes that would otherwise get an induction rejected or need fixing after it’s loaded:

  • Missing or invalid data: required fields for each Action, allowed dropdown values, number formats, GTIN length and check digit, prohibited characters.
  • Rules between fields: Case Size must be a multiple of Inner Size, one primary supplier per item, one Case/Each/Inner row per GTIN, department-specific requirements.
  • Live RMS lookups: whether the supplier, Dept/Class/Subclass, size, UDA values or GTIN already exist, and whether a new child item matches its parent’s hierarchy and retail.
  • Description quality: brand at the start, proper case, spelling, size and colour words that don’t belong, the 100-character limit.

Every problem cell is colour-highlighted, many get a comment explaining the exact fix, and a pass/fail stamp with your user name and the time is written to cells A2–A4, so a reviewer can see the file was checked before it was submitted.

Email Count

Email Count measures the Data Steward Team’s workload straight from Outlook. One click scans the team’s shared mailbox, picks out the item induction and maintenance requests, and builds a PivotTable of request emails per day. Use it for weekly workload reports, to spot spikes around seasonal or ad deadlines, or to back up staffing and turnaround-time discussions with real numbers instead of estimates.

  • Reads the Data Steward Team mailbox only, never your personal inbox.
  • Counts mail in the team’s working folders: Inbox, each team member’s personal folder, Item Induction and Item Maintenance.
  • Keeps only emails whose subject looks like a request (e.g. Item Induction, Add Supplier, GTIN Delete) and drops confirmations such as Successful Upload.
  • Writes every matching email to a RawData sheet and summarises it on PivotResult.

Email Count workbook

How to Use It

  1. Make sure Outlook (desktop) is open and the Data Steward Team shared mailbox appears in your folder pane.
  2. Open ExportEmailToPivot.xlsm and enable macros.
  3. On Sheet1, click Update Pivot Table. It can take 1–2 minutes on a full mailbox; Excel looks frozen while Outlook is read.
  4. If a folder can’t be found you’ll get a list of the ones skipped; the rest are still counted.
  5. When “Done. n matching emails processed into the pivot table.” appears, you’re taken to PivotResult.
Each run deletes and rebuilds the RawData and PivotResult sheets, so they always reflect the mailbox as it is now. Copy the numbers somewhere else (or save the workbook under a dated name) if you want to keep a weekly history.

Things to Keep in Mind

  • Every email counts, including replies. A request with three RE: replies in the same folder counts four times. Treat the number as email volume, not unique requests.
  • Keywords match inside words. Short keywords such as AIS, MIM or NIB also match words that contain them, and COMPLETE also excludes subjects with Completed or Incomplete. Spot-check RawData if a number looks off.
  • Only what’s still in the folders. Emails moved elsewhere, archived or deleted aren’t counted, and read Inbox mail is skipped.
  • One folder per name. If the mailbox has two folders with the same name, only the first one found is counted.
  • Adding a team member or a new keyword means editing the folder and keyword lists in the macro (Alt+F11, Module1).
