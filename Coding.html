Promotion Macro

The Promotion Macro turns a vendor’s Navy Deal Offer Form (DOF) into a ready-to-key START promotion template in one click. When you click Export Promotion it:

  1. Builds the START promotion template rows (item, zone, fixed price, retail, comments).
  2. Logs the promotion to the brand’s tab in the Buyer Promo Tracker and checks for overlapping promotions.
  3. Optionally loads the items into the Fact Tags workbook for sale signs.
  4. Saves the template to the shared promotions folder, split into one file per month for long promotions.
  5. Drafts the Outlook email to the right team with the file attached, ready for you to review and send.

Save both workbooks to a shared path your team can access. The macro opens the START template, the tracker and the Fact Tags workbook from the paths in its CONFIGURATION section, so update those paths to your team’s folders first (see Assign Tracker Path).

Before You Run It

  • Brand tab exists in the tracker. The tracker must have a tab named exactly like the vendor/brand name you enter in the macro (e.g. MSI). See Brand Tabbing.
  • Paths are set. The START template, tracker and Fact Tags paths in the code point to files you can open.
  • Outlook is installed and signed in, so the macro can draft the email.
  • Close the tracker on other computers if possible. The macro saves it, and a copy someone else has open will be read-only.

The macro then runs on its own. Here’s what happens, in order:

  1. Builds the template. Opens the START promotion template and fills one row per item.
  2. Logs to the tracker. Opens the Buyer Promo Tracker, finds the tab named after the brand, adds the rows under the last entry with the promo dates, scanback $ and the Sent to START answer, then saves the tracker.
  3. Checks for overlaps. The tracker’s Overlap Check column (C) flags any item already on promotion for those dates. If any row says Overlap, you’ll see “Overlap Detected! Check Tracker.” and the macro stops: no file is saved and no email is drafted.
  4. Loads Fact Tags (if you said Yes).
  5. Saves the file(s). The file is named m.d.yy-m.d.yy Brand Month Promotion.xlsx, e.g. 3.1.26-3.31.26 MSI March Promotion.xlsx. Missing brand/month folders are created automatically.
  6. Drafts the email (if sending now) and shows “Process Complete.”
Long promotions are split by month. If the promotion runs longer than 31 days, the macro creates one file (and one email) per calendar month. Example: 3/15/26–5/10/26 produces 3.15.26-3.31.26 … March, 4.1.26-4.30.26 … April and 5.1.26-5.10.26 … May.
If an overlap is detected: the new rows have already been added to the tracker (that’s how the overlap was found). Look at the brand tab, fix the dates or items, delete the rows the macro just added, then run the macro again.

The macro behind the Export Promotion button. Network paths and email addresses are redacted; replace them with your team’s.

VBA 
Sub VendorDOF()
    Dim SourceWB As Workbook, TemplateWB As Workbook, TrackerWB As Workbook
    Dim FactMasterWB As Workbook
    Dim BaseSavePath As String, SaveFolderPath As String, FileName As String, FullSavePath As String
    Dim OutApp As Object, OutMail As Object
    Dim TemplatePath As String, TrackerPath As String, FactMasterPath As String
    Dim LastDataRow As Long, i As Long
    Dim DateDiffVal As Long, TotalDuration As Long
    Dim EmailTo As String, EmailSubject As String, EmailBody As String
    Dim BrandName As String, PromoMonth As String, PromoDates As String
    Dim OverlapFound As Boolean
    Dim SendNowResponse As VbMsgBoxResult, FactTagResponse As VbMsgBoxResult
    
    Dim StartDate As Date, EndDate As Date
    Dim CurrentStart As Date, CurrentEnd As Date
    Dim fso As Object
    Set fso = CreateObject("Scripting.FileSystemObject")
    
    ' --- USER PROMPTS ---
    SendNowResponse = MsgBox("Will you send promotion now?", vbYesNo + vbQuestion, "Promotion Status")
    FactTagResponse = MsgBox("Do you want to generate sale tags?", vbYesNo + vbQuestion, "Fact Tags Status")
    
    ' --- OPTIMIZATION ---
    Application.ScreenUpdating = False
    Application.Calculation = xlCalculationAutomatic
    
    Set SourceWB = ThisWorkbook
    StartDate = SourceWB.Worksheets(1).Range("B14").Value
    EndDate = SourceWB.Worksheets(1).Range("D14").Value
    BrandName = SourceWB.Worksheets(1).Range("C26").Value
    TotalDuration = EndDate - StartDate
    
    ' --- CONFIGURATION ---
    TemplatePath = "\\SERVER\Shared\Templates\Promotion Template.xlsx"
    TrackerPath = "\\SERVER\Buyer Promos\2026\Buyer Promo Tracker 2026.xlsm"
    FactMasterPath = "\\SERVER\Fact Tags\Fact Tags V4.xlsm"

    LastDataRow = SourceWB.Worksheets(1).Range("B30:G333").Find("*", SearchOrder:=xlByRows, SearchDirection:=xlPrevious).Row
    If LastDataRow < 30 Then LastDataRow = 30
    Dim rowCount As Long: rowCount = (LastDataRow - 30)

    ' --- PART 1: PREPARE MASTER DATA BLOCK ---
    Set TemplateWB = Workbooks.Open(TemplatePath)
    With TemplateWB.Worksheets(1)
        For i = 14 To (14 + rowCount)
            .Cells(i, "I").Value = "Item"
            .Cells(i, "P").Value = "Zone"
            .Cells(i, "R").Value = "3391"
            .Cells(i, "T").Value = "Fixed Price"
            .Cells(i, "Y").Value = "Both Regular and Clearance"
        Next i
        .Range("M14:M317, W14:W317, AA14:AA317, AB14:AB317").UnMerge
        SourceWB.Worksheets(1).Range("D30:D" & LastDataRow).Copy: .Range("M14").PasteSpecial xlPasteValues
        SourceWB.Worksheets(1).Range("G30:G" & LastDataRow).Copy: .Range("W14").PasteSpecial xlPasteValues
        SourceWB.Worksheets(1).Range("B30:B" & LastDataRow).Copy: .Range("AA14").PasteSpecial xlPasteValues
        SourceWB.Worksheets(1).Range("F30:F" & LastDataRow).Copy: .Range("AB14").PasteSpecial xlPasteValues
    End With

    ' --- PART 2: UPDATE TRACKER ONCE ---
    On Error Resume Next
    Set TrackerWB = Workbooks(Dir(TrackerPath))
    If TrackerWB Is Nothing Then Set TrackerWB = Workbooks.Open(TrackerPath)
    On Error GoTo 0
    
    If Not TrackerWB Is Nothing Then
        Dim TargetSheet As Worksheet
        Set TargetSheet = TrackerWB.Worksheets(BrandName)
        If Not TargetSheet Is Nothing Then
            Dim TrackerNextRow As Long
            TrackerNextRow = TargetSheet.Cells(TargetSheet.Rows.Count, "M").End(xlUp).Row + 1
            TemplateWB.Worksheets(1).Range("G14:AB" & (14 + rowCount)).Copy
            TargetSheet.Range("G" & TrackerNextRow).PasteSpecial Paste:=xlPasteValues
            TargetSheet.Range("G" & TrackerNextRow).Resize(rowCount + 1).Value = StartDate
            TargetSheet.Range("H" & TrackerNextRow).Resize(rowCount + 1).Value = EndDate
            SourceWB.Worksheets(1).Range("I30:I" & LastDataRow).Copy: TargetSheet.Range("AC" & TrackerNextRow).PasteSpecial Paste:=xlPasteValues
            TargetSheet.Range("AF" & TrackerNextRow).Resize(rowCount + 1).Value = IIf(SendNowResponse = vbYes, "Yes", "No")
            Application.Calculate
            DoEvents
            For i = TrackerNextRow To (TrackerNextRow + rowCount)
                If Trim(LCase(TargetSheet.Cells(i, "C").Text)) = "overlap" Then OverlapFound = True
            Next i
            TrackerWB.Save
        End If
    End If

    If OverlapFound Then
        MsgBox "Overlap Detected! Check Tracker.", vbCritical
        TemplateWB.Close SaveChanges:=False
        GoTo CleanUp
    End If

    ' --- PART 3: UPDATE FACT TAGS ONCE ---
    If FactTagResponse = vbYes Then
        On Error Resume Next
        Set FactMasterWB = Workbooks(Dir("Fact Tags V4.xlsm"))
        If FactMasterWB Is Nothing Then Set FactMasterWB = Workbooks.Open(FactMasterPath)
        On Error GoTo 0
        If Not FactMasterWB Is Nothing Then
            With FactMasterWB.Worksheets("Sale Master")
                With .Range("D2").Resize(rowCount + 1)
                    .NumberFormat = "@": .Value = SourceWB.Worksheets(1).Range("D30:D" & LastDataRow).Value
                End With
                SourceWB.Worksheets(1).Range("F30:F" & LastDataRow).Copy: .Range("L2").PasteSpecial xlPasteValues
                SourceWB.Worksheets(1).Range("G30:G" & LastDataRow).Copy: .Range("M2").PasteSpecial xlPasteValues
                .Range("H2").Resize(rowCount + 1).Value = StartDate
                .Range("I2").Resize(rowCount + 1).Value = EndDate
            End With
        End If
    End If

    ' --- PART 4: FILE GENERATION LOOP ---
    Set OutApp = CreateObject("Outlook.Application")
    CurrentStart = StartDate

    Do
        ' Duration Logic
        If TotalDuration > 31 Then
            CurrentEnd = DateSerial(Year(CurrentStart), Month(CurrentStart) + 1, 0)
            If CurrentEnd > EndDate Then CurrentEnd = EndDate
            PromoMonth = Format(CurrentStart, "mmmm")
        Else
            CurrentEnd = EndDate
            PromoMonth = Format(StartDate, "mmmm")
        End If
        
        PromoDates = Format(CurrentStart, "m.d.yy") & "-" & Format(CurrentEnd, "m.d.yy")
        FileName = PromoDates & " " & BrandName & " " & PromoMonth & " Promotion"
        
        ' --- REVISED DYNAMIC PATHS ---
        If SendNowResponse = vbYes Then
            ' Save to: ...\2026\[Brand Name]\[Month]\
            SaveFolderPath = "\\SERVER\Buyer Promos\2026\" & BrandName & "\" & PromoMonth & "\"
        Else
            ' Save to: ...\2026\Send Later\[Month]\[Brand Name]\
            SaveFolderPath = "\\SERVER\Buyer Promos\2026\Send Later\" & PromoMonth & "\" & BrandName & "\"
        End If
        
        ' Recursive creation ensures the full brand/month tree exists
        If Not fso.FolderExists(SaveFolderPath) Then CreateFolderRecursive fso, SaveFolderPath
        FullSavePath = SaveFolderPath & FileName & ".xlsx"

        ' Update Template Headers
        With TemplateWB.Worksheets(1)
            .Range("C4:I4").UnMerge
            .Range("C4").Value = FileName
            .Range("C4:I4").Merge
            .Range("K2").Value = SourceWB.Worksheets(1).Range("D26").Value
            .Range("G2").Value = SourceWB.Worksheets(1).Range("C27").Value
            .Range("C6").Value = CurrentStart
            .Range("E6").Value = CurrentEnd
        End With

        Application.DisplayAlerts = False
        TemplateWB.SaveCopyAs FullSavePath
        Application.DisplayAlerts = True

        ' --- EMAIL ---
        If SendNowResponse = vbYes Then
            DateDiffVal = DateDiff("d", Date, CurrentStart)
            EmailTo = IIf(DateDiffVal <= 7, "DMM@example.org", "START-TEAM@example.org")
            EmailSubject = IIf(DateDiffVal <= 7, "URGENT Pricing - ", "BP - ") & FileName
            
            Set OutMail = OutApp.CreateItem(0)
            With OutMail
                .To = EmailTo: .Subject = EmailSubject
                .Body = "Hello," & vbCrLf & vbCrLf & "Attached is the promotion file for " & BrandName & " during " & PromoMonth & "."
                .Attachments.Add FullSavePath: .Display
            End With
        End If

        If TotalDuration <= 31 Then Exit Do
        CurrentStart = DateSerial(Year(CurrentStart), Month(CurrentStart) + 1, 1)
        If CurrentStart > EndDate Then Exit Do
    Loop

    TemplateWB.Close SaveChanges:=False

CleanUp:
    Application.ScreenUpdating = True
    Application.CutCopyMode = False
    MsgBox "Process Complete.", vbInformation
End Sub

' Recursive Folder Helper
Sub CreateFolderRecursive(fso As Object, path As String)
    If Not fso.FolderExists(fso.GetParentFolderName(path)) Then
        CreateFolderRecursive fso, fso.GetParentFolderName(path)
    End If
    If Not fso.FolderExists(path) Then fso.CreateFolder path
End Sub

ThisWorkbook code (also in the download): after the first save the workbook locks itself, so the master copy can’t be saved over by accident. Use File → Save As if you need your own copy.

VBA 
Private Sub Workbook_BeforeSave(ByVal SaveAsUI As Boolean, Cancel As Boolean)
    Dim nm As Name
    Static IsInternalSave As Boolean
    
    ' If this is the code itself triggering a save, let it through
    If IsInternalSave Then Exit Sub

    ' 1. Check for the permanent lock
    On Error Resume Next
    Set nm = ThisWorkbook.Names("PERMA_LOCK17")
    On Error GoTo 0

    ' 2. If the lock exists, block the save
    If Not nm Is Nothing Then
        MsgBox "This workbook is locked and cannot be saved again.", vbCritical
        Cancel = True
        Exit Sub
    End If

    ' 3. First time saving? Create the lock and FORCE it to stick.
    ' We turn off events so we don't trigger an infinite loop.
    Application.EnableEvents = False
    IsInternalSave = True
    
    ' Add the hidden flag
    ThisWorkbook.Names.Add Name:="PERMA_LOCK16", RefersTo:="=1", Visible:=False
    
    ' Force the workbook to save right now with the new flag
    ThisWorkbook.Save
    
    MsgBox "First save successful. This file is now permanently locked.", vbInformation
    
    IsInternalSave = False
    Application.EnableEvents = True
    
    ' Cancel the original save request because we just did it manually
    Cancel = True
End Sub

Sub GetTotalSalesForSelectedRINs()
    Dim cn As Object, rs As Object
    Dim cell As Range, mySelection As Range
    Dim strSQL As String, itemList As String, sqlTemplate As String
    Dim startDate As String, endDate As String
    Dim dict As Object
    
    ' 1. Initial Checks
    Set mySelection = Selection
    If mySelection Is Nothing Then Exit Sub
    
    ' Get SQL Template from the named range
    On Error Resume Next
    sqlTemplate = Range("rngrmsquery").Value
    On Error GoTo 0
    
    If sqlTemplate = "" Then
        MsgBox "Could not find SQL query in 'rngrmsquery'. Please check the named range.", vbCritical
        Exit Sub
    End If

    ' 2. Prompt for Date Range
    startDate = InputBox("Enter Start Date (MM/DD/YYYY):", "Sales Start", Format(Date - 7, "mm/dd/yyyy"))
    If startDate = "" Then Exit Sub
    endDate = InputBox("Enter End Date (MM/DD/YYYY):", "Sales End", Format(Date, "mm/dd/yyyy"))
    If endDate = "" Then Exit Sub

    ' 3. Build Item List for SQL
    For Each cell In mySelection
        If Not IsEmpty(cell) Then
            itemList = itemList & "'" & Trim(cell.Value) & "',"
        End If
    Next cell
    
    If Len(itemList) > 0 Then
        itemList = Left(itemList, Len(itemList) - 1)
    Else
        MsgBox "Please select RINs first.", vbExclamation
        Exit Sub
    End If

    ' 4. Prepare Final SQL
    strSQL = Replace(sqlTemplate, "{ITEM_LIST}", itemList)
    strSQL = Replace(strSQL, "{START_DATE}", startDate)
    strSQL = Replace(strSQL, "{END_DATE}", endDate)

    ' 5. Database Connection
    On Error GoTo oraerror
    Set cn = CreateObject("ADODB.Connection")
    cn.Open "Driver={Microsoft ODBC for Oracle};Server=YOUR_SERVER;Uid=YOUR_USER_ID;Pwd=" & zzz() & ";"

    Set rs = CreateObject("ADODB.Recordset")
    rs.Open strSQL, cn

    ' 6. Map Results to Dictionary for Speed
    Set dict = CreateObject("Scripting.Dictionary")
    Do While Not rs.EOF
        dict(CStr(rs.Fields(0).Value)) = rs.Fields(1).Value
        rs.MoveNext
    Loop

    ' 7. Write Totals to Column AG
    Application.ScreenUpdating = False
    For Each cell In mySelection
        If dict.Exists(CStr(cell.Value)) Then
            ' Offset from current cell to Column AG (Column 33)
            ' This calculates the distance from the current column to AG
            Cells(cell.Row, "AG").Value = dict(CStr(cell.Value))
        Else
            Cells(cell.Row, "AG").Value = 0
        End If
    Next cell
    Application.ScreenUpdating = True

    MsgBox "Total Sales updated in Column AG.", vbInformation
    
CleanUp:
    On Error Resume Next
    If Not rs Is Nothing Then rs.Close
    If Not cn Is Nothing Then cn.Close
    Exit Sub

oraerror:
    MsgBox "Oracle Error: " & Err.Description, vbCritical
    Resume CleanUp
End Sub

Regular Fact Tags (Category Tabs)

Regular fact tags are the everyday shelf signs for items on display. Sub QuickConsolidateAndSort()
    Dim wsMaster As Worksheet, ws As Worksheet
    Dim sheetNames As Variant
    Dim dataArr As Variant, combinedArr() As Variant
    Dim i As Long, r As Long, c As Long
    Dim totalRows As Long, totalCols As Long
    Dim lastRow As Long
    Dim rowOffset As Long
    Dim sourceRange As Range
    Dim cell As Range

    sheetNames = Array("Apple", "Audio", "Computers", "Cameras", "Mobile Electronics", "Smart Home", "TV-Video", "Video Games", "Majors", "ASOS", "Small Appliances")
    Set wsMaster = ThisWorkbook.Sheets("Master")

    ' Unprotect Master sheet if needed
    On Error Resume Next
    wsMaster.Unprotect Password:="********"
    On Error GoTo 0

    ' Clear Master sheet except header
    wsMaster.Rows("2:" & wsMaster.Rows.Count).ClearContents

    ' Define fixed column range: A to M (columns 1 to 13)
    totalCols = 13

    ' First pass: calculate total rows needed
    totalRows = 0
    For i = LBound(sheetNames) To UBound(sheetNames)
        Set ws = ThisWorkbook.Sheets(sheetNames(i))
        lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row
        If lastRow >= 6 Then
            totalRows = totalRows + (lastRow - 6 + 1)
        End If
    Next i

    ' Exit if no data
    If totalRows = 0 Then
        MsgBox "No data to consolidate.", vbExclamation
        Exit Sub
    End If

    ' Initialize combined array
    ReDim combinedArr(1 To totalRows, 1 To totalCols)
    rowOffset = 0

    ' Second pass: fill combined array
    For i = LBound(sheetNames) To UBound(sheetNames)
        Set ws = ThisWorkbook.Sheets(sheetNames(i))
        lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row
        If lastRow >= 6 Then
            Set sourceRange = ws.Range("A6:M" & lastRow)
            If sourceRange.Rows.Count = 1 Then
                ReDim dataArr(1 To 1, 1 To totalCols)
                For c = 1 To totalCols
                    dataArr(1, c) = sourceRange.Cells(1, c).Value
                Next c
            Else
                dataArr = sourceRange.Value
            End If

            For r = 1 To UBound(dataArr, 1)
                For c = 1 To totalCols
                    combinedArr(rowOffset + r, c) = dataArr(r, c)
                Next c
            Next r
            rowOffset = rowOffset + UBound(dataArr, 1)
        End If
    Next i

    ' Dump combined data into Master starting at A2
    wsMaster.Range("A2").Resize(totalRows, totalCols).Value = combinedArr

    ' Force columns E and G to text
    wsMaster.Range("E:E").NumberFormat = "@"
    wsMaster.Range("G:G").NumberFormat = "@"
    For Each cell In wsMaster.Range("E2:E" & totalRows + 1)
        If Not IsEmpty(cell.Value) Then cell.Value = CStr(cell.Value)
    Next cell
    For Each cell In wsMaster.Range("G2:G" & totalRows + 1)
        If Not IsEmpty(cell.Value) Then cell.Value = CStr(cell.Value)
    Next cell

    ' Sort by column L (12th column)
    On Error Resume Next ' Shared mode may block sorting
    With wsMaster.Sort
        .SortFields.Clear
        .SortFields.Add Key:=wsMaster.Range("L2:L" & totalRows + 1), _
            SortOn:=xlSortOnValues, Order:=xlDescending, DataOption:=xlSortNormal
        .SetRange wsMaster.Range("A1").Resize(totalRows + 1, totalCols)
        .Header = xlYes
        .Apply
    End With
    On Error GoTo 0

    ' Log last update time
    wsMaster.Range("Z1").Value = "Last updated: " & Format(Now, "yyyy-mm-dd hh:mm AM/PM")

    ' Re-protect Master sheet
    wsMaster.Protect Password:="********", AllowSorting:=True, AllowFiltering:=True

    ' Show random dad joke
    MsgBox GetRandomDadJoke(), vbInformation, "Master Tab Updated"
End Sub

Sub SaveWorkbookSafe(wb As Workbook, fullPath As String)
    On Error GoTo SaveErr

Sub SALEMASTER()
    Dim sourceSheet As Worksheet
    Dim targetWB As Workbook
    Dim tempWB As Workbook
    Dim lastRow As Long, i As Long
    Dim targetPath As String, tempFilePath As String
    Dim fileName As String, emailSubject As String, emailBody As String
    Dim rawStart As String, rawEnd As String, deptName As String
    Dim dateStart As Date, dateEnd As Date
    Dim fiscalYearStart As Date
    Dim weekNum As Long
    Dim OutApp As Object, OutMail As Object
    
    ' 1. Get User Inputs
    deptName = InputBox("Enter the Department (e.g., Electronics):", "Department Name")
    rawStart = InputBox("Enter Promotion Start Date (MM/DD/YY):", "Start Date")
    rawEnd = InputBox("Enter Promotion End Date (MM/DD/YY):", "End Date")
    
    If deptName = "" Or rawStart = "" Or rawEnd = "" Then Exit Sub

    ' Convert text inputs to Date variables
    On Error Resume Next
    dateStart = CDate(rawStart)
    dateEnd = CDate(rawEnd)
    On Error GoTo 0

    If dateStart = 0 Or dateEnd = 0 Then
        MsgBox "Invalid date format. Please use MM/DD/YY.", vbCritical
        Exit Sub
    End If

    ' 2. Calculate Fiscal Week based on Start Date
    fiscalYearStart = DateSerial(Year(dateStart), 2, 1)
    If dateStart < fiscalYearStart Then
        fiscalYearStart = DateSerial(Year(dateStart) - 1, 2, 1)
    End If
    weekNum = Int((dateStart - fiscalYearStart) / 7) + 1
    If weekNum > 52 Then weekNum = 52
    If weekNum < 1 Then weekNum = 1

    ' 3. Format Naming Strings
    Dim fStart As String, fEnd As String, sStart As String, sEnd As String
    fStart = Format(dateStart, "yyyymmdd"): fEnd = Format(dateEnd, "yyyymmdd")
    sStart = Format(dateStart, "mm.dd.yyyy"): sEnd = Format(dateEnd, "mm.dd.yyyy")
    
    fileName = "Week " & weekNum & " Unadvertised " & deptName & " Promotion Fact Tag_99999_Promotion_SIGNS_HQ Distributed_" & fStart & "_" & fEnd & ".xlsx"
    emailSubject = "Week " & weekNum & " " & deptName & " Unadvertised Promotion Fact Tags " & sStart & "-" & sEnd
    emailBody = "Sign Team," & vbCrLf & vbCrLf & "Please see attached Sale signs for Week " & weekNum & " for " & deptName & "." & vbCrLf & vbCrLf & "Thanks,"

    ' 4. Process Files
    Set sourceSheet = ThisWorkbook.ActiveSheet
    lastRow = sourceSheet.Cells(sourceSheet.Rows.Count, "D").End(xlUp).Row
    targetPath = "\\SERVER\Shared\Templates\Fact Tags\Fact Tags.xlsx"
    
    Application.ScreenUpdating = False

    On Error Resume Next
    Set targetWB = Workbooks.Open(fileName:=targetPath, ReadOnly:=True)
    On Error GoTo 0
    
    If targetWB Is Nothing Then
        MsgBox "Target file not found.", vbCritical
        Application.ScreenUpdating = True
        Exit Sub
    End If

    ' Paste everything as values into ItemImport tab
    sourceSheet.Range("A2:M" & lastRow).Copy
    targetWB.Sheets("ItemImport").Range("A2").PasteSpecial Paste:=xlPasteValues
    Application.CutCopyMode = False

    ' --- NEW CLEANING LOGIC: DELETE ROWS WITH #N/A IN COLUMN C ---
    With targetWB.Sheets("ItemImport")
        Dim templateLastRow As Long
        templateLastRow = .Cells(.Rows.Count, "C").End(xlUp).Row
        
        ' Loop backwards when deleting rows to avoid skipping
        For i = templateLastRow To 2 Step -1
            If IsError(.Cells(i, "C").Value) Then
                If .Cells(i, "C").Value = CVErr(xlErrNA) Then
                    .Rows(i).Delete
                End If
            End If
        Next i
    End With
    ' -------------------------------------------------------------

    ' 5. Create Temp File and Email
    targetWB.Sheets("ItemImport").Copy
    Set tempWB = ActiveWorkbook
    
    tempFilePath = Environ$("temp") & "\" & fileName
    If Dir(tempFilePath) <> "" Then Kill tempFilePath
    
    tempWB.SaveAs tempFilePath
    tempWB.Close SaveChanges:=False
    targetWB.Close SaveChanges:=False

    ' 6. Outlook Integration
    Set OutApp = CreateObject("Outlook.Application")
    Set OutMail = OutApp.CreateItem(0)

    With OutMail
        .To = "SignTeam@example.org"
        .Subject = emailSubject
        .Body = emailBody
        .Attachments.Add tempFilePath
        .Display
    End With

    Set OutMail = Nothing: Set OutApp = Nothing
    Application.ScreenUpdating = True
End Sub

How lift is measured

Baseline = the item’s normal, un-promoted sales. For each item, the Baseline Avg/Wk is the average weekly units it sold over the last 26 weeks excluding ad weeks. That answers “what does this item sell when we don’t advertise it?”, which is the right comparison, rather than a calendar-year average.

  • Unit Lift = ad week units − baseline: the extra units the ad drove.
  • Lift % = unit lift ÷ baseline: the headline number for one item.
  • Weighted Lift % (Lift Query) = total unit lift ÷ total baseline units across a group of items.
When you’re quoting…Use
One itemIts Lift % on the Ad Summary.
A vendor, product line or whole adThe Weighted Lift % from the Lift Query. It counts every unit equally, so it matches the actual extra units the ad drove.
A simple average of several items’ Lift %Don’t. Small items with big percentages inflate it.

                            End If

                            Exit Do
                        End If
                        rsAccess.MoveNext
                    Loop
                    If historicalInfo <> "" Or imageDeliveryInfo <> "" Then recordFound = True
                End If
            End If
            
            If Not recordFound Then
                If Not rsAccess Is Nothing Then If rsAccess.State = 1 Then rsAccess.Close
                strAccessSQL = "SELECT [Ad Information], [Image Delivery], [RIN or Item List] FROM Main WHERE [RIN or Item List] LIKE '%" & currentItem & "%' ORDER BY [ID] DESC"
                Set rsAccess = CreateObject("ADODB.Recordset")

                rsAccess.Open strAccessSQL, cnAccess, 1, 1
                
                Do While Not rsAccess.EOF
                    testList = Trim(CStr(rsAccess.Fields("RIN or Item List").Value))
                    pos = InStr(1, testList, currentItem)
                    
                    Do While pos > 0
                        isTrueMatch = True
                        If pos > 1 Then
                            charBefore = Mid(testList, pos - 1, 1)
                            If charBefore Like "[0-9]" Then isTrueMatch = False
                        End If
                        
                        If pos + Len(currentItem) <= Len(testList) Then
                            charAfter = Mid(testList, pos + Len(currentItem), 1)

                            End If
                        End If

                    Loop
                    
                    If historicalInfo <> "" And imageDeliveryInfo <> "" Then
                        recordFound = True
                        Exit Do
                    End If
                    rsAccess.MoveNext

            Set rs = Nothing


            ' ========================================================
            ' PART 2: RUN ACCESS PULL (CHRONOLOGICAL HYBRID LOGIC ENGINE)
            ' ========================================================
            recordFound = False
            historicalInfo = ""
            
            ' Strategy A: Search by strict Numeric ID (Sorted by newest [ID] first)
            If IsNumeric(currentItem) Then
                strAccessSQL = "SELECT [Ad Information] FROM Main WHERE [ID] = " & val(currentItem) & " ORDER BY [ID] DESC"
                Set rsAccess = CreateObject("ADODB.Recordset")
                rsAccess.CursorLocation = 3
                On Error Resume Next
                rsAccess.Open strAccessSQL, cnAccess, 1, 1
                On Error GoTo oraerror
                If Not rsAccess.EOF Then
                    Do While Not rsAccess.EOF
                        If Not IsNull(rsAccess.Fields("Ad Information").Value) And Trim(rsAccess.Fields("Ad Information").Value) <> "" Then
                            historicalInfo = rsAccess.Fields("Ad Information").Value
                            recordFound = True
                            Exit Do
                        End If
                        rsAccess.MoveNext
                    Loop
                End If
            End If
            
            ' Strategy B: Text-based exact ID comparison (Sorted by newest [ID] first)
            If Not recordFound Then
                If Not rsAccess Is Nothing Then If rsAccess.State = 1 Then rsAccess.Close
                strAccessSQL = "SELECT [Ad Information] FROM Main WHERE CStr([ID]) = '" & currentItem & "' ORDER BY [ID] DESC"
                Set rsAccess = CreateObject("ADODB.Recordset")
                rsAccess.CursorLocation = 3
                rsAccess.Open strAccessSQL, cnAccess, 1, 1
                If Not rsAccess.EOF Then
                    Do While Not rsAccess.EOF
                        If Not IsNull(rsAccess.Fields("Ad Information").Value) And Trim(rsAccess.Fields("Ad Information").Value) <> "" Then
                            historicalInfo = rsAccess.Fields("Ad Information").Value
                            recordFound = True
                            Exit Do
                        End If
                        rsAccess.MoveNext
                    Loop
                End If
            End If
            
            ' Strategy C: VBA-Validated Text Array Filter (Sorted by newest [ID] first)
            If Not recordFound Then
                If Not rsAccess Is Nothing Then If rsAccess.State = 1 Then rsAccess.Close
                
                ' Pull records containing the substring sorted dynamically by latest Entry ID
                strAccessSQL = "SELECT [Ad Information], [RIN or Item List] FROM Main WHERE [RIN or Item List] LIKE '%" & currentItem & "%' ORDER BY [ID] DESC"
                Set rsAccess = CreateObject("ADODB.Recordset")
                rsAccess.CursorLocation = 3
                rsAccess.Open strAccessSQL, cnAccess, 1, 1
                
                ' Programmatic boundary valuation loop (Checking top records first)
                Do While Not rsAccess.EOF
                    testList = Trim(CStr(rsAccess.Fields("RIN or Item List").Value))
                    pos = InStr(1, testList, currentItem)
                    
                    Do While pos > 0
                        isTrueMatch = True
                        
                        ' Confirm preceding character boundary
                        If pos > 1 Then
                            charBefore = Mid(testList, pos - 1, 1)
                            If charBefore Like "[0-9]" Then isTrueMatch = False
                        End If
                        
                        ' Confirm trailing character boundary
                        If pos + Len(currentItem) <= Len(testList) Then
                            charAfter = Mid(testList, pos + Len(currentItem), 1)
                            If charAfter Like "[0-9]" Then isTrueMatch = False
                        End If
                        
                        ' Save and break out as soon as the first verified true match with text is hit
                        If isTrueMatch Then
                            If Not IsNull(rsAccess.Fields("Ad Information").Value) And Trim(rsAccess.Fields("Ad Information").Value) <> "" Then
                                historicalInfo = rsAccess.Fields("Ad Information").Value
                                recordFound = True
                                Exit Do
                            End If
                        End If
                        
                        pos = InStr(pos + 1, testList, currentItem)
                    Loop
                    
                    If recordFound Then Exit Do
                    rsAccess.MoveNext
                Loop
            End If

            ' --- POPULATE RESOLVED DATA INTO EXCEL CELL (COLUMN 11 = K) ---
            If recordFound Then
                ThisWS.Cells(cellRow.Row, 11).Value = historicalInfo
            Else
                ThisWS.Cells(cellRow.Row, 11).Value = ""
            End If

            If Not rsAccess Is Nothing Then If rsAccess.State = 1 Then rsAccess.Close
            Set rsAccess = Nothing

        End If

    Next cellRow

    ' --- CLEANUP CONNECTIONS ---
    If cn.State = 1 Then cn.Close
    Set cn = Nothing
    If cnAccess.State = 1 Then cnAccess.Close
    Set cnAccess = Nothing

    Application.Cursor = xlDefault
    MsgBox "Rows " & Replace(UpdateRange, "A", "") & " successfully updated with Oracle Data and Newest Access Ad Info.", vbInformation, "Done!"
    Exit Sub

oraerror:
    Application.Cursor = xlDefault
    MsgBox "Error encountered: " & Err.Description, vbCritical, "Database Sync Issue"

    If Not cn Is Nothing Then If cn.State = 1 Then cn.Close
    Set cn = Nothing
    If Not cnAccess Is Nothing Then If cnAccess.State = 1 Then cnAccess.Close
    Set cnAccess = Nothing
End Sub

Sub WeekSelectorConfirm()

    Dim wsImp As Worksheet
    Dim wsSum As Worksheet
    Set wsImp = ThisWorkbook.Sheets("Data Import")
    Set wsSum = ThisWorkbook.Sheets("Ad Summary")

    Dim wsSel As Worksheet
    On Error Resume Next
    Set wsSel = ThisWorkbook.Sheets("_WeekSelector")

    If wsSel Is Nothing Then

    End If

    Dim ww As Long

    For ww = 1 To m_uniqueWeekCount

        If cbx.Value = xlOn Then
            selAdWeekCount = selAdWeekCount + 1
            selAdWeeks(selAdWeekCount) = m_uniqueWeeks(ww)
        End If
    Next ww

    Dim userInput As String
    userInput = ""
    For ww = 1 To selAdWeekCount
        If ww = 1 Then
            userInput = selAdWeeks(ww)
        Else
            userInput = userInput & ", " & selAdWeeks(ww)
        End If
    Next ww

    Application.DisplayAlerts = False
    wsSel.Delete
    Application.DisplayAlerts = True

    If selAdWeekCount = 0 Then
        MsgBox "No weeks checked.", vbInformation, "NEX"
        Exit Sub
    End If

    Dim selWeekDict As Object
    Set selWeekDict = CreateObject("Scripting.Dictionary")
    For ww = 1 To selAdWeekCount
        If Not selWeekDict.Exists(UCase(selAdWeeks(ww))) Then
            selWeekDict.Add UCase(selAdWeeks(ww)), ww
        End If
    Next ww

    Dim totalRows       As Long
    Dim totalAdRows     As Long
    Dim dataRowCount    As Long
    Dim lastDataR       As Long
    Dim outRow          As Long
    Dim i               As Long
    Dim nn              As Integer
    Dim hc              As Long
    Dim ak              As Long
    Dim vRow            As Long
    Dim colonPos        As Long
    Dim txnBlWks        As Long
    Dim adVal           As Variant
    Dim blVal           As Variant
    Dim allAdKeys       As Variant
    Dim rawStyle        As String
    Dim txnRIN          As String
    Dim weekVal         As String
    Dim parentRIN       As String
    Dim descVal         As String
    Dim grpVal          As String
    Dim deptVal         As String
    Dim classVal        As String
    Dim subClassVal     As String
    Dim adKey           As String
    Dim blKey           As String
    Dim adWeekStr       As String
    Dim verdict         As String
    Dim cellVerdict     As String
    Dim noiseWords(2)   As String
    Dim mainHeaders(1 To 12) As String
    Dim mainWidths(1 To 12) As Integer
    Dim extHeaders(1 To 4) As String
    Dim extWidths(1 To 4) As Integer
    Dim mainOut         As Variant
    Dim extOut          As Variant
    Dim isNoise         As Boolean
    Dim isAdWeek        As Boolean
    Dim salesUTY        As Double
    Dim salesTY         As Double
    Dim salesULC        As Double
    Dim salesRLC        As Double
    Dim blAvg           As Double
    Dim liftU           As Double
    Dim liftP           As Double
    Dim liftR           As Double
    Dim txnBlU          As Double
    Dim txnBlR          As Double
    Dim hdrBg           As Long
    Dim hdrFg           As Long
    Dim adDict          As Object
    Dim blDict          As Object
    Dim tblRange        As Range
    Dim tbl             As ListObject

    Set adDict = CreateObject("Scripting.Dictionary")
    Set blDict = CreateObject("Scripting.Dictionary")

    totalRows = m_totalRows
    noiseWords(0) = "UNSCANNED"
    noiseWords(1) = "DEMO"
    noiseWords(2) = "SPECIAL ORDER"

    Application.StatusBar = "NEX: Processing " & totalRows & " rows..."
    Application.ScreenUpdating = False

    ' -- Pass 1: Group rows into dictionaries ---------------------
    ' Column map: 1=Group 2=Dept 3=Class 4=Sub-Class 5=SKU
    '             6=Style NEW 7=Week 8=Metrics 9=Sales$
    '             10=SalesU 11=Sales$LC26W 12=SalesULC26W 13=InvOHU
    Application.StatusBar = "NEX: Processing " & totalRows & " rows..."
    Application.ScreenUpdating = False

    For i = 1 To totalRows

        If i Mod 2000 = 0 Then
            Application.StatusBar = "NEX: Processing row " & i & " of " & totalRows & "..."
        End If

        rawStyle = Trim(CStr(m_dataArr(i, 6)))
        txnRIN = Trim(CStr(m_dataArr(i, 5)))
        weekVal = Trim(CStr(m_dataArr(i, 7)))
        grpVal = Trim(CStr(m_dataArr(i, 1)))
        deptVal = Trim(CStr(m_dataArr(i, 2)))
        classVal = Trim(CStr(m_dataArr(i, 3)))
        subClassVal = Trim(CStr(m_dataArr(i, 4)))

        If rawStyle = "" Or rawStyle = "False" Or txnRIN = "" Then GoTo NextRow1

        isNoise = False
        For nn = 0 To 2
            If InStr(1, UCase(rawStyle), noiseWords(nn)) > 0 Then
                isNoise = True
                Exit For
            End If
        Next nn
        If isNoise Then GoTo NextRow1

        colonPos = InStr(rawStyle, ":")
        If colonPos > 1 Then
            parentRIN = Trim(Left(rawStyle, colonPos - 1))
            descVal = Trim(Mid(rawStyle, colonPos + 1))
        Else
            parentRIN = rawStyle
            descVal = rawStyle
        End If

        salesUTY = 0: salesTY = 0
        salesULC = 0: salesRLC = 0
        If IsNumeric(m_dataArr(i, 9)) Then salesTY = CDbl(m_dataArr(i, 9))
        If IsNumeric(m_dataArr(i, 10)) Then salesUTY = CDbl(m_dataArr(i, 10))
        If IsNumeric(m_dataArr(i, 12)) Then salesULC = CDbl(m_dataArr(i, 12))
        If IsNumeric(m_dataArr(i, 11)) Then salesRLC = CDbl(m_dataArr(i, 11))

        isAdWeek = selWeekDict.Exists(UCase(weekVal))
        adWeekStr = weekVal

        If isAdWeek Then
            adKey = adWeekStr & "|" & parentRIN & "|" & txnRIN
            If adDict.Exists(adKey) Then
                adVal = adDict(adKey)
                adVal(0) = adVal(0) + salesUTY
                adVal(1) = adVal(1) + salesTY
                adDict(adKey) = adVal
            Else
                ' Slots: 0=units 1=rev 2=desc 3=parent 4=txn 5=week
                '        6=group 7=dept 8=class 9=subclass
                adVal = Array(salesUTY, salesTY, descVal, parentRIN, txnRIN, adWeekStr, _
                              grpVal, deptVal, classVal, subClassVal)
                adDict.Add adKey, adVal
            End If
        Else
            If salesULC > 0 Then
                blKey = "BL|" & parentRIN & "|" & txnRIN
                If blDict.Exists(blKey) Then
                    blVal = blDict(blKey)
                    blVal(0) = blVal(0) + salesULC
                    blVal(1) = blVal(1) + salesRLC
                    blVal(2) = blVal(2) + 1
                    blDict(blKey) = blVal
                Else
                    blVal = Array(salesULC, salesRLC, 1)
                    blDict.Add blKey, blVal
                End If
            End If
        End If

        txnBlR = 0

        If blDict.Exists(blKey) Then
            blVal = blDict(blKey)
            txnBlU = blVal(0)
            txnBlR = blVal(1)
            txnBlWks = blVal(2)
        End If

        blAvg = 0
        If txnBlWks > 0 Then blAvg = txnBlU / txnBlWks
        liftU = adVal(0) - blAvg
        liftP = 0
        If blAvg > 0 Then liftP = liftU / blAvg
        liftR = 0
        If txnBlWks > 0 Then liftR = adVal(1) - (txnBlR / txnBlWks)

        If txnBlWks = 0 And adVal(0) = 0 Then
            verdict = "No Data"
        ElseIf txnBlWks = 0 Then
            verdict = "NEW LAUNCH"
        ElseIf txnBlWks < 4 Then
            verdict = "LOW DATA (" & txnBlWks & " wks)"
        ElseIf liftP >= 0.5 Then
            verdict = "STRONG"
        ElseIf liftP >= 0.2 Then
            verdict = "MODERATE"
        Else
            verdict = "WEAK"
        End If

        outRow = outRow + 1
        mainOut(outRow, 1) = adVal(5)
        mainOut(outRow, 2) = adVal(3)
        mainOut(outRow, 3) = adVal(4)
        mainOut(outRow, 4) = adVal(2)
        mainOut(outRow, 5) = adVal(0)
        mainOut(outRow, 6) = adVal(1)
        If blAvg > 0 Then
            mainOut(outRow, 7) = blAvg
            mainOut(outRow, 8) = txnBlWks
            mainOut(outRow, 9) = liftU
            mainOut(outRow, 10) = liftP
            mainOut(outRow, 11) = liftR
        Else
            mainOut(outRow, 7) = ""
            mainOut(outRow, 8) = txnBlWks
            mainOut(outRow, 9) = ""
            mainOut(outRow, 10) = ""
            mainOut(outRow, 11) = ""

    Dim wsImp   As Worksheet

    Set wsSum = ThisWorkbook.Sheets("Ad Summary")

    Dim predRIN         As String
    Dim lastDataRow     As Long

    Dim ak              As Long
    Dim nn              As Integer
    Dim colonPos        As Long
    Dim txnBlWks        As Long
    Dim searchStart     As Long
    Dim outRow          As Long
    Dim resultCount     As Long
    Dim rawStyle        As String
    Dim txnRIN          As String

    Dim blAvg           As Double
    Dim liftU           As Double
    Dim liftP           As Double
    Dim liftR           As Double
    Dim txnBlU          As Double
    Dim txnBlR          As Double
    Dim noiseWords(2)   As String
    Dim dataArr         As Variant
    Dim adVal           As Variant
    Dim blVal           As Variant
    Dim allAdKeys       As Variant
    Dim adDict          As Object
    Dim blDict          As Object
    Dim calWeekDict     As Object
    Dim rBg             As Long
    Dim vBg             As Long
    Dim altRow          As Long

    predRIN = Trim(CStr(wsSum.Range("M3").Value))
    If predRIN = "" Or predRIN = "Enter predecessor Parent RIN here" Then
        MsgBox "Enter a predecessor Parent RIN in the search box first.", _
               vbExclamation, "NEX - No RIN Entered"
        Exit Sub
    End If

    Dim wsCal As Worksheet
    Set wsCal = ThisWorkbook.Sheets("Ad Week Calendar")
    Set calWeekDict = CreateObject("Scripting.Dictionary")
    Dim calRow As Long
    Dim calCode As String
    For calRow = 4 To 200
        calCode = Trim(CStr(wsCal.Cells(calRow, 4).Value))
        If calCode <> "" And calCode <> "False" Then
            If Not calWeekDict.Exists(UCase(calCode)) Then
                calWeekDict.Add UCase(calCode), calCode
            End If
        End If
    Next calRow

    Dim useCalendar As Boolean
    useCalendar = (calWeekDict.Count > 0)

    Application.StatusBar = "NEX Lookup: Reading data..."
    Application.ScreenUpdating = False

    lastDataRow = wsImp.Cells(wsImp.Rows.Count, 5).End(xlUp).Row
    If lastDataRow < 6 Then
        Application.StatusBar = False
        Application.ScreenUpdating = True
        MsgBox "No data in Data Import tab. Paste your QuantaSense export first.", _
               vbExclamation, "NEX"
        Exit Sub
    End If

    dataArr = wsImp.Range("A5:M" & lastDataRow).Value
    totalRows = UBound(dataArr, 1)

    noiseWords(0) = "UNSCANNED"
    noiseWords(1) = "DEMO"
    noiseWords(2) = "SPECIAL ORDER"

    Set blDict = CreateObject("Scripting.Dictionary")

        rawStyle = Trim(CStr(dataArr(i, 6)))

            parentRIN = Trim(Left(rawStyle, colonPos - 1))

                adVal(1) = adVal(1) + salesTY

                adVal = Array(salesUTY, salesTY, descVal, parentRIN, txnRIN, adWeekStr)
                adDict.Add adKey, adVal
            End If

                blKey = "BL|" & parentRIN & "|" & txnRIN

                    blVal = blDict(blKey)
                    blVal(0) = blVal(0) + salesULC
                    blVal(1) = blVal(1) + salesRLC
                    blVal(2) = blVal(2) + 1
                    blDict(blKey) = blVal
                Else
                    blVal = Array(salesULC, salesRLC, 1)
                    blDict.Add blKey, blVal
                End If
            End If
        End If

NextRow2:
    Next i

        .RowHeight = 24
    End With

    predHeaders(2) = "Parent RIN"

    predHeaders(4) = "Description"
    predHeaders(5) = "Ad Wk Units"
    predHeaders(6) = "Ad Wk Rev ($)"

    predHeaders(10) = "Lift %"
    predHeaders(11) = "Rev Lift ($)"
    predHeaders(12) = "Verdict"

    For ph = 1 To 12
        With wsSum.Cells(outRow, ph)
            .Value = predHeaders(ph)
            .Font.Name = "Arial"
            .Font.Bold = True
            .Font.Size = 10
            .Font.Color = RGB(255, 255, 255)
            .Interior.Color = RGB(29, 46, 114)
            .HorizontalAlignment = xlCenter
            .VerticalAlignment = xlCenter
            .WrapText = True
            .RowHeight = 30
        End With
    Next ph
    outRow = outRow + 1

    resultCount = 0

    If adDict.Count = 0 Then
        wsSum.Range(wsSum.Cells(outRow, 1), wsSum.Cells(outRow, 12)).Merge
        With wsSum.Cells(outRow, 1)
            .Value = "No ad week data found for Parent RIN " & predRIN & _
                                   " in this paste.   " & _
                                   "This item may not have been advertised during this period, " & _
                                   "or it may not yet have sales data (new launch / no PO cut)."
            .Font.Name = "Arial"
            .Font.Italic = True
            .Font.Size = 10
            .Font.Color = RGB(132, 60, 12)
            .Interior.Color = RGB(252, 228, 214)
            .HorizontalAlignment = xlLeft
            .VerticalAlignment = xlCenter
            .WrapText = True
            .RowHeight = 32
        End With
    Else
        allAdKeys = adDict.Keys
        altRow = 0
        For ak = 0 To UBound(allAdKeys)
            adKey = allAdKeys(ak)
            adVal = adDict(adKey)

            blKey = "BL|" & adVal(3) & "|" & adVal(4)
            txnBlU = 0: txnBlR = 0: txnBlWks = 0
            If blDict.Exists(blKey) Then
                blVal = blDict(blKey)
                txnBlU = blVal(0)
                txnBlR = blVal(1)
                txnBlWks = blVal(2)
            End If

            blAvg = 0
            If txnBlWks > 0 Then blAvg = txnBlU / txnBlWks
            liftU = adVal(0) - blAvg
            liftP = 0
            If blAvg > 0 Then liftP = liftU / blAvg
            liftR = 0
            If txnBlWks > 0 Then liftR = adVal(1) - (txnBlR / txnBlWks)

                verdict = "No Data"
            ElseIf txnBlWks = 0 Then
                verdict = "NEW LAUNCH"
            ElseIf txnBlWks < 4 Then
                verdict = "LOW DATA (" & txnBlWks & " wks)"
            ElseIf liftP >= 0.5 Then
                verdict = "STRONG"
            ElseIf liftP >= 0.2 Then
                verdict = "MODERATE"
            Else
                verdict = "WEAK"
            End If

            altRow = altRow + 1
            rBg = IIf(altRow Mod 2 = 0, RGB(242, 245, 248), RGB(255, 255, 255))

            vBg = RGB(242, 245, 248)
            If verdict = "STRONG" Then vBg = RGB(198, 239, 206)

                Call PredWriteCell(wsSum.Cells(outRow, 11), "---", rBg, RGB(74, 74, 74), False, "center")
            End If

            Call PredWriteCell(wsSum.Cells(outRow, 12), verdict, vBg, RGB(74, 74, 74), True, "center")

            resultCount = resultCount + 1
            outRow = outRow + 1
        Next ak
    End If

    Application.StatusBar = False
    Application.ScreenUpdating = True
    wsSum.Cells(searchStart, 1).Select

    If resultCount > 0 Then
        MsgBox "Predecessor lookup complete." & vbCrLf & vbCrLf & _
               "Parent RIN: " & predRIN & vbCrLf & _
               resultCount & " ad week rows found." & vbCrLf & vbCrLf & _

VBA 
Option Explicit

' ================================================================
' NEX Lift Query - filters AdSummaryTable by week / description / sub-class
' Reads from Ad Summary tab (already-computed lift values)
' Writes results to Lift Query tab
'
' Inputs (Lift Query tab):
'   B3 = Ad Week(s) - comma-separated, blank = all
'   B4 = Description contains - blank = no filter
'   B5 = Class contains - blank = no filter
'   B6 = Sub-Class contains - blank = no filter
'
' Button calls: RunLiftQuery
' ================================================================

Sub RunLiftQuery()

    Dim wsSum As Worksheet
    Dim wsQry As Worksheet
    Set wsSum = ThisWorkbook.Sheets("Ad Summary")
    Set wsQry = ThisWorkbook.Sheets("Lift Query")

    ' Read filters
    Dim adWeekInput As String
    Dim descInput   As String
    Dim clsInput    As String
    Dim subInput    As String
    adWeekInput = Trim(CStr(wsQry.Range("B3").Value))
    descInput = LCase(Trim(CStr(wsQry.Range("B4").Value)))
    clsInput = LCase(Trim(CStr(wsQry.Range("B5").Value)))
    subInput = LCase(Trim(CStr(wsQry.Range("B6").Value)))

    ' Build week filter dictionary
    Dim weekDict As Object
    Set weekDict = CreateObject("Scripting.Dictionary")
    Dim useWeekFilter As Boolean
    useWeekFilter = (adWeekInput <> "")

    If useWeekFilter Then
        Dim wkParts() As String
        wkParts = Split(adWeekInput, ",")
        Dim wp As Long
        For wp = 0 To UBound(wkParts)
            Dim wk As String
            wk = UCase(Trim(wkParts(wp)))
            If wk <> "" Then
                If Not weekDict.Exists(wk) Then weekDict.Add wk, 1
            End If
        Next wp
    End If

    ' Find last data row in Ad Summary (col E has units, never blank for valid rows)
    Dim lastSumRow As Long

Sub Update_Selected_RINs()
    Dim wsBulk As Worksheet
    Dim headerRange As Range
    
    ' Variables for the RIN column
    Dim rinDestHeader As Range
    Dim destRinColumn As Long
    Dim cell As Range
    Dim selectedRinRange As Range
    
    ' Dynamic Header Variables
    Dim imgDestHeader As Range
    Dim destImgColumn As Long
    
    ' Oracle Database Variables
    Dim cn As Object
    Dim rs As Object
    Dim strSQL As String
    Dim currentBulkRow As Long
    Dim RCount As Long
    
    ' Access Database Variables
    Dim cnAccess As Object
    Dim rsAccess As Object
    Dim strAccessSQL As String
    Dim dbAccessPath As String
    Dim currentItem As String
    Dim recordFound As Boolean
    Dim historicalInfo As String
    Dim imageDeliveryInfo As String
    
    ' Validation boundary checking variables
    Dim testList As String
    Dim pos As Long
    Dim charBefore As String
    Dim charAfter As String
    Dim isTrueMatch As Boolean
    
    ' Variable for splitting supplier information
    Dim rawSupplierInfo As String

    ' Set sheet safely
    Set wsBulk = ThisWorkbook.Sheets("Ad Database Import")
    
    ' Access file configuration path
    dbAccessPath = "\\SERVER\Ad Database\AdDB.accdb"
    
    ' Find the "RIN" header on Row 5
    Set rinDestHeader = wsBulk.Rows(5).Find(What:="RIN", LookIn:=xlValues, LookAt:=xlWhole, MatchCase:=False)
    
    ' Dynamically locate the "Image" Header on Row 5
    Set imgDestHeader = wsBulk.Rows(5).Find(What:="Image", LookIn:=xlValues, LookAt:=xlWhole, MatchCase:=False)
    
    If rinDestHeader Is Nothing Then
        MsgBox "Could not find required header 'RIN' on Row 5 of Ad Database Import!", vbCritical
        Exit Sub
    End If
    
    destRinColumn = rinDestHeader.Column
    
    ' Determine Image Column destination safely (Fallback to Column 14 / N if header can't be matched)
    If Not imgDestHeader Is Nothing Then
        destImgColumn = imgDestHeader.Column
    Else
        destImgColumn = 14 ' Column N
    End If
    
    ' Intersect selection with the actual RIN column to avoid processing wrong selections
    Set selectedRinRange = Intersect(Selection, wsBulk.Columns(destRinColumn))
    
    If selectedRinRange Is Nothing Then
        MsgBox "Please select the cells containing the RIN numbers in the correct column before clicking the button.", vbExclamation
        Exit Sub
    End If
    
    ' ==========================================
    ' QUERY ATTRIBUTES FROM ORACLE & ACCESS
    ' ==========================================
    Set cn = CreateObject("ADODB.Connection")
    Set cnAccess = CreateObject("ADODB.Connection")
    
    On Error GoTo oraerror
    
    ' Open connection to Oracle RMS
    cn.Open "Driver={Microsoft ODBC for Oracle};Server=RMS_SERVER;Uid=READ_ONLY_USER;Pwd=" & zzz() & ";"
    
    ' Open connection to local Access AdDB File
    cnAccess.Open "Provider=Microsoft.ACE.OLEDB.12.0;Data Source=" & dbAccessPath
    
    Application.Cursor = xlWait
    Application.ScreenUpdating = False
    
    ' Loop cell-by-cell strictly through highlighted cells
    For Each cell In selectedRinRange
        ' Skip the header row if accidentally included in selection
        If cell.Row > 5 And Trim(CStr(cell.Value)) <> "" Then
            
            currentBulkRow = cell.Row
            currentItem = Trim(CStr(cell.Value))
            
            ' Pull query base text and swap placeholder token for current cell
            strSQL = ThisWorkbook.Sheets("SQL").Range("rngrmsquery").Value
            strSQL = Replace(strSQL, "ITEMS", currentItem)
            
            ' Verify cell contains a valid transaction key structure before querying databases
            If IsNumeric(currentItem) And Len(currentItem) > 5 Then
               
                ' --------------------------------------------------------
                ' A. ORACLE DATA INGESTION
                ' --------------------------------------------------------
                Set rs = CreateObject("ADODB.Recordset")
                rs.CursorLocation = 3 ' 3 = adUseClient
                rs.Open strSQL, cn
                
                If Not rs.EOF Then
                    RCount = rs.RecordCount
                    
                    If RCount = 1 Then
                        ' Imports values matching the exact column names/aliases in your SQL string
                        wsBulk.Range("E" & currentBulkRow).Value = rs("VPN")
                        wsBulk.Range("AP" & currentBulkRow).Value = rs("Parent RIN")
                        wsBulk.Range("F" & currentBulkRow).Value = rs("Description")
                        wsBulk.Range("P" & currentBulkRow).Value = rs("Retail")
                        wsBulk.Range("AM" & currentBulkRow).Value = rs("Dept")
                        wsBulk.Range("AN" & currentBulkRow).Value = rs("Class")
                        wsBulk.Range("U" & currentBulkRow).Value = rs("Cost")
                        wsBulk.Range("AQ" & currentBulkRow).Value = rs("Cost")
                        
                        ' Pull Supplier Info (Format: "SupplierID:SupplierName")
                        rawSupplierInfo = Trim(CStr(rs("Supplier Information")))
                        
                        ' Extract ID and Name via Split
                        If InStr(rawSupplierInfo, ":") > 0 Then
                            wsBulk.Range("B" & currentBulkRow).Value = Split(rawSupplierInfo, ":")(0)
                            wsBulk.Range("C" & currentBulkRow).Value = Split(rawSupplierInfo, ":")(1)
                        Else
                            wsBulk.Range("B" & currentBulkRow).Value = rawSupplierInfo
                            wsBulk.Range("C" & currentBulkRow).Value = ""
                        End If
                    End If
                End If
                
                If rs.State = 1 Then rs.Close
                Set rs = Nothing
                
                ' --------------------------------------------------------
                ' B. ACCESS HISTORICAL DATA PULL
                ' --------------------------------------------------------
                recordFound = False
                historicalInfo = ""
                imageDeliveryInfo = ""
                
                ' Strategy 1: Search by strict Numeric ID
                If IsNumeric(currentItem) Then
                    strAccessSQL = "SELECT [Ad Information], [Image Delivery] FROM Main WHERE [ID] = " & val(currentItem) & " ORDER BY [ID] DESC"
                    Set rsAccess = CreateObject("ADODB.Recordset")
                    rsAccess.CursorLocation = 3
                    On Error Resume Next
                    rsAccess.Open strAccessSQL, cnAccess, 1, 1
                    On Error GoTo oraerror
                    If Not rsAccess.EOF Then
                        Do While Not rsAccess.EOF
                            If historicalInfo = "" Then
                                If Not IsNull(rsAccess.Fields("Ad Information").Value) And Trim(rsAccess.Fields("Ad Information").Value) <> "" Then
                                    historicalInfo = rsAccess.Fields("Ad Information").Value
                                End If
                            End If
                            If imageDeliveryInfo = "" Then
                                If Not IsNull(rsAccess.Fields("Image Delivery").Value) And Trim(rsAccess.Fields("Image Delivery").Value) <> "" Then
                                    imageDeliveryInfo = rsAccess.Fields("Image Delivery").Value
                                End If
                            End If
                            If historicalInfo <> "" And imageDeliveryInfo <> "" Then
                                recordFound = True
                                Exit Do
                            End If
                            rsAccess.MoveNext
                        Loop
                        If historicalInfo <> "" Or imageDeliveryInfo <> "" Then recordFound = True
                    End If
                End If
                
                ' Strategy 2: Text-based exact ID comparison
                If Not recordFound Then
                    If Not rsAccess Is Nothing Then If rsAccess.State = 1 Then rsAccess.Close
                    strAccessSQL = "SELECT [Ad Information], [Image Delivery] FROM Main WHERE CStr([ID]) = '" & currentItem & "' ORDER BY [ID] DESC"
                    Set rsAccess = CreateObject("ADODB.Recordset")
                    rsAccess.CursorLocation = 3
                    rsAccess.Open strAccessSQL, cnAccess, 1, 1
                    If Not rsAccess.EOF Then
                        Do While Not rsAccess.EOF
                            If historicalInfo = "" Then
                                If Not IsNull(rsAccess.Fields("Ad Information").Value) And Trim(rsAccess.Fields("Ad Information").Value) <> "" Then
                                    historicalInfo = rsAccess.Fields("Ad Information").Value
                                End If
                            End If
                            If imageDeliveryInfo = "" Then
                                If Not IsNull(rsAccess.Fields("Image Delivery").Value) And Trim(rsAccess.Fields("Image Delivery").Value) <> "" Then
                                    imageDeliveryInfo = rsAccess.Fields("Image Delivery").Value
                                End If
                            End If
                            If historicalInfo <> "" And imageDeliveryInfo <> "" Then
                                recordFound = True
                                Exit Do
                            End If
                            rsAccess.MoveNext
                        Loop
                        If historicalInfo <> "" Or imageDeliveryInfo <> "" Then recordFound = True
                    End If
                End If
                
                ' Strategy 3: VBA-Validated Text Array Filter
                If Not recordFound Then
                    If Not rsAccess Is Nothing Then If rsAccess.State = 1 Then rsAccess.Close
                    
                    strAccessSQL = "SELECT [Ad Information], [Image Delivery], [RIN or Item List] FROM Main WHERE [RIN or Item List] LIKE '%" & currentItem & "%' ORDER BY [ID] DESC"
                    Set rsAccess = CreateObject("ADODB.Recordset")
                    rsAccess.CursorLocation = 3
                    rsAccess.Open strAccessSQL, cnAccess, 1, 1
                    
                    Do While Not rsAccess.EOF
                        testList = Trim(CStr(rsAccess.Fields("RIN or Item List").Value))
                        pos = InStr(1, testList, currentItem)
                        
                        Do While pos > 0
                            isTrueMatch = True
                            
                            If pos > 1 Then
                                charBefore = Mid(testList, pos - 1, 1)
                                If charBefore Like "[0-9]" Then isTrueMatch = False
                            End If
                            
                            If pos + Len(currentItem) <= Len(testList) Then
                                charAfter = Mid(testList, pos + Len(currentItem), 1)
                                If charAfter Like "[0-9]" Then isTrueMatch = False
                            End If
                            
                            If isTrueMatch Then
                                If historicalInfo = "" Then
                                    If Not IsNull(rsAccess.Fields("Ad Information").Value) And Trim(rsAccess.Fields("Ad Information").Value) <> "" Then
                                        historicalInfo = rsAccess.Fields("Ad Information").Value
                                    End If
                                End If
                                If imageDeliveryInfo = "" Then
                                    If Not IsNull(rsAccess.Fields("Image Delivery").Value) And Trim(rsAccess.Fields("Image Delivery").Value) <> "" Then
                                        imageDeliveryInfo = rsAccess.Fields("Image Delivery").Value
                                    End If
                                End If
                            End If
                            
                            pos = InStr(pos + 1, testList, currentItem)
                        Loop
                        
                        If historicalInfo <> "" And imageDeliveryInfo <> "" Then
                            recordFound = True
                            Exit Do
                        End If
                        rsAccess.MoveNext
                    Loop
                    If historicalInfo <> "" Or imageDeliveryInfo <> "" Then recordFound = True
                End If
                
                ' Map Ad Information to Column G
                If historicalInfo <> "" Then
                    wsBulk.Range("G" & currentBulkRow).Value = historicalInfo
                Else
                    wsBulk.Range("G" & currentBulkRow).Value = ""
                End If
                
                ' Output historical Image Delivery Info
                wsBulk.Cells(currentBulkRow, destImgColumn).Value = imageDeliveryInfo
                
                If Not rsAccess Is Nothing Then If rsAccess.State = 1 Then rsAccess.Close
                Set rsAccess = Nothing
                
            Else
                ' Clear query fields if item number structure is fundamentally invalid
                wsBulk.Cells(currentBulkRow, destImgColumn).Value = ""
                wsBulk.Range("G" & currentBulkRow).Value = ""
            End If
        End If
    Next cell
    
    ' Close Active Database Connections safely
    If cn.State = 1 Then cn.Close
    Set cn = Nothing
    If cnAccess.State = 1 Then cnAccess.Close
    Set cnAccess = Nothing
    
    Application.ScreenUpdating = True
    Application.Cursor = xlDefault
    
    MsgBox "Processing Complete! Selected records updated contextually in-place.", vbInformation
    Exit Sub

oraerror:
    Application.ScreenUpdating = True
    Application.Cursor = xlDefault
    MsgBox "Database Connectivity Error: " & Err.Description, vbExclamation, "Data Refresh Failed"
    
    If Not cn Is Nothing Then If cn.State = 1 Then cn.Close
    Set cn = Nothing
    If Not cnAccess Is Nothing Then If cnAccess.State = 1 Then cnAccess.Close
    Set cnAccess = Nothing
End Sub

Private Function GetDetailedFormSQL(itemVal As String, locs As String) As String
    Dim s As String
    s = "SELECT il.loc ""LOCATION"", (SELECT Store_Name FROM Store WHERE Store=il.loc) ""LOC_NAME"", "
    s = s & "im.item ""ITEM_TRANS"", im.item_parent ""ITEM_PARENT"", im.item_desc ""DESCRIPTION"", im.dept ""DEPT"", "
    s = s & "isu.supplier ""PRIMARY_SUPPLIER"", (SELECT sup2.sup_name FROM sups sup2 WHERE sup2.supplier=il.primary_supp) ""VENDOR"", "
    s = s & "TO_CHAR(ils.last_sold, 'mm/dd/yyyy') ""LAST_SOLD"", "
    s = s & "TO_CHAR(ils.last_received, 'mm/dd/yyyy') ""LAST_REC"", " ' Added Field
    s = s & "decode(ils.loc_type,'S', ils.stock_on_hand,0) ""STORE_OH"", "
    s = s & "(decode(ils.loc_type,'S', ils.stock_on_hand,0)+decode(ils.loc_type,'W', ils.stock_on_hand,0)+ils.in_transit_qty) AS ""OH_TOTAL"", "
    s = s & "nvl(ril.min_stock,0) ""MIN_QTY"", nvl(ril.max_stock,0) ""MAX_QTY"" "
    s = s & "FROM (SELECT * from item_master WHERE (item IN (" & itemVal & ") OR item_parent IN (" & itemVal & ")) AND tran_level = item_level) im "
    s = s & "LEFT JOIN rms.item_loc il ON im.item=il.item "
    s = s & "LEFT JOIN rms.item_supplier isu ON im.item=isu.item AND il.item=isu.item "
    s = s & "LEFT JOIN rms.item_loc_soh ils ON im.item=ils.item AND il.loc=ils.loc "
