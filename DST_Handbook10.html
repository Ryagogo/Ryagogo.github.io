How to Submit a Delete GTIN Induction Form to DST
*Note: This is to delete GTINs out of RMS and downstream systems.

For Buying Teams:
You must provide a reason for all Delete requests in the body of the email.  DST has been tasked to track all deletes as there are downstream ramifications when we process any delete requests.  NOTE: Please Do Not put the reason in the Subject Line
Reminder/Notes:
- If the Transaction Item the GTIN is currently attached to has multiple GTINs, please make sure the GTIN being deleted is NOT flagged as primary.  If it is, you must change the primary flag to another GTIN.  This is a hard stop for RMS as the purge job will error and will delay your request as it will be sent back to you for updating.
- If your Delete should only be happening in a single system (i.e. RMSv16 Only or RMSv10 Only).  You MUST notate that in your email or the delete will automatically be processed for both systems.
- If you are requesting to delete at Parent or Trans level, please be aware the items MUST meet the purge criteria in order to delete – no transactions of any kind for 2 years àIf there are any transactions out there it is a hard stop.
- If you will be building new items with these GTINs, please DO NOT attach the new Item Induction to the Delete request email.  It must be submitted to DST separately after the delete has processed.
To delete a GTIN through the Custom Item Induction template, please follow these steps:
Email Response 
- Select Action = ‘Add Item CFAS’ (Column A)
- Enter GTIN(s) or Parent/Trans to be deleted in the Parent Item (Column H) - this should be whatever level you are trying to delete (i.e. GTIN, Trans, or Parent).
- Enter Buyer Number in the Buyer (Column DK)
DO NOT POPULATE ANY OTHER FIELDS:
Email Response 
- Submit and E-mail to the DST (as an Excel Macro-Enabled Workbook) with DELETE GTIN (or ITEM) Request in the Subject Line

If you have any questions, please let us know.

Thank you,

Range Already-Built Items to a Destination Dept (e.g., 781) Check (Pulls web description, brand, MSRP, VPN, supplier color, and e-comm UDA values for items being ranged into an already-built dept/class/subclass.)

SQL 
SELECT DISTINCT im.item_grandparent AS PARENT, im.item_parent AS TRANSACTION, im.dept, xim.item_desc_secondary AS WEB_DESC, xim.brand_name AS BRAND, xim.MFG_REC_RETAIL AS MSRP, iss.VPN AS VPN, iss.SUPP_DIFF_1 AS SUPPLIER_COLOR, uil.UDA_ID AS ECOMM_UDA, uil.UDA_VALUE AS ECOMM_UDA_VALUE 
FROM rms.item_master im JOIN rms.item_supplier iss ON im.item_parent = iss.item 
LEFT JOIN rms.uda_item_lov uil ON im.item_parent = uil.item 
AND uil.UDA_ID IN ('9630', '9631', '9632', '9627') 
JOIN (SELECT item, brand_name, mfg_rec_retail, item_desc_secondary FROM rms.item_master) xim 
ON xim.item = im.item_parent 
WHERE im.item_grandparent IN ('19507468','19507466','19507467') 
AND iss.primary_supp_ind = 'Y' 
ORDER BY im.dept, im.item_grandparent, im.item_parent ASC, uil.uda_value DESC;

Item Reclassification

DocumentSOP-S.05.1.2 · Item Re-class (v16 & v10)
AuthorData Steward Team
ScopeMandatory: all DST members

What it is

A re-class moves an approved item from one department/class/subclass to another in RMS. Buying teams request them through the DST Inbox; DST checks that the item can safely move, keys the re-class in RMS v16 (and in RMS v10 where required), and the change is applied by the nightly batch. Most of the work is in the checks beforehand: forecasting, mandatory UDAs, open orders on the deals tables, pack components and financial (Lawson) moves are the usual reasons a re-class fails.

Key factDetail
Non-financial re-classesProcessed monthly, during the 1st full week of the month.
Financial re-classesProcessed twice a year, directly after inventories (February and August).
Item levelIn v16, always re-class at the Parent level (Level 1, formerly the Grandparent in v10). Packs are the only 2-level items.
Item listsRequired when more than five items go to the same dept/class/subclass. A separate list is needed for v16 and v10.
Nightly volumeSoft cap of 25,000 items per night, counting all items exploded out.
When it runsThe re-class job runs in Phase 4 of the nightly batch (the after-batch), the night before the effective date.
Closing POsOrders that must be closed have to be closed in v16 by 1 pm EST so the change flows to v10.

Process at a glance

  1. Receive the request in the DST Inbox and check the re-class form is complete.
  2. Run the pre-re-class checks: forecasting, mandatory UDAs, hierarchy changes, financial moves, and open or pack orders.
  3. Key the re-class in RMS v16, and in v10 (single item or item list) where required.
  4. Report the night's item count before leaving for the day.
  5. After the batch, validate the results and fix any failures (open orders, pack components).
  6. Reply to the original email with the canned response once validation is complete.

Third Party Gift Cards (TPGC)

What it is

Third Party Gift Cards (TPGC) are gift cards from outside brands such as Starbucks, Target or Visa that are sold at the register. They are built in RMS as non-merchandise items, so they never flow to Xadmin on their own. Instead, each card is loaded into Xadmin through a set of .mnt (maintenance) files created with the MNT Creator workbook, most quickly by using the TPGC Cheat Sheet. The STS team is also given the card details so sales audit treats them correctly, and ORUP is told about the new RINs so the Non-Merchandise Master File stays current.

⚠
Do NOT create Third Party Gift Cards in Xadmin. They must be input into Xadmin through a series of MNT (maintenance) files.

Create Third Party Gift Cards in RMS as Non-Merchandise

  1. If creating the item via the front end, be sure to deselect the Merchandise check box.
  2. If creating the item via induction, change column AS (Merchandise) from Y to N.
  3. Item Loc Trait Qty/Key Options = Prohibited
  4. Electronic Market Basket Code = Gift Card
  5. Manual Price Entry = Required for Range cards and Prohibited for Fixed cards
  6. Returnable = No
ℹ
Note: Non-merchandise items should not have locations ranged to them, so they do not flow to Xadmin.

Card Types & MNT Files Needed

Every TPGC is one of four types, based on whether its value is fixed or a range, and whether a fee is charged on top.

Card typeExample
Fixed – No FeeStarbucks $10 Gift Card
Fixed – FeeVisa $50 Gift Card, 1.5% fee
Range – No FeeTarget $10–$500 Gift Card
Range – FeeVisa $10–$500 Gift Card, 1.5% fee

Depending on the type of card, you may need to create up to four .mnt files. Each one is named after the tab in the MNT Creator workbook that produces it. There is no required order of deployment, but all files for a card must be deployed on the same day.

Card typeMNT files (tabs) needed
Fixed – No FeeTPGCNonMerchandise · TPGC_UPC · ItemPriceAction
Fixed – FeeTPGCNonMerchandise · TPGC_UPC · TPGCAttachFee · ItemPriceAction
Range – No FeeTPGCNonMerchandise · TPGC_UPC · GCITMProperties
Range – FeeTPGCNonMerchandise · TPGC_UPC · GCITMProperties · TPGCAttachFee

What each tab does:

  • TPGCNonMerchandise – enters all the details of the gift card.
  • TPGC_UPC – attaches a UPC to the gift card.
  • ItemPriceAction – assigns a retail price to a fixed price card.
  • GCITMProperties – sets the minimum and maximum value of a range card.
  • TPGCAttachFee – attaches the fee item to a card that carries a fee.

TPGC Cheat Sheet: Automated MNT Creation

The TPGC Cheat Sheet is a macro-enabled workbook that streamlines the MNT Master Creator inputs. Instead of filling out up to five converter tabs by hand and pressing Ctrl+Shift+M on each one, you enter one row per gift card on the cheat sheet and click Export. The ExportTPGC macro routes each row by its card type, writes the right rows and default values into every tab the card needs, keeps those tabs in sync, and then builds all the .mnt files in one pass.

Using the cheat sheet

  1. Open TPGC_Cheat_Sheet.xlsm and enable content.
  2. On the TPGC tab, enter one row per gift card starting on row 4, using the column guide above.
  3. Stay on the TPGC tab and click the blue Export button. The macro reads whichever sheet is active, so don't run it from another tab.
  4. The macro checks that every header on row 3 is present, opens the Master Creator, and checks that each target tab and header exists. If anything is missing it stops and lists what it couldn't find, before writing anything.
  5. Each row is validated for its card type. A row is written only if it passes every check, so a card never ends up on some tabs but not others.
  6. A summary shows how many rows were exported for each card type, how many TPGCAttachFee and GCITMProperties rows were added, and any skipped rows with the reason (for example Row 7: missing/invalid Fixed Retail).
  7. Answer Yes to Create the MNT file(s) now?. Choose No if you want to review the Master Creator tabs first. The Master Creator is left open on the TPGC_UPC tab.
  8. A Check the data prompt lists each populated tab with its row count, last column and last cell value. If a count or last column looks wrong, select No: there is probably old or hidden data to delete below the last row or to the right of the last column.
  9. Choose the folder to save the files in (for example your U drive).
  10. One file is created per populated tab, named MNTCreation_<Tab>-<username><yyyy_mm_dd_hhmm>.mnt, and a final message lists them. Deploy them all on the same day.

'==============================================================================
' Main
'==============================================================================
Public Sub ExportTPGC()
    Dim wbTgt As Workbook, lastSrc As Long, r As Long
    Dim giftType As String, missing As String, summary As String

    On Error GoTo Fail
    nNoFee = 0: nFee = 0: nRangeNoFee = 0: nRangeFee = 0
    nAF = 0: nGCP = 0: nSkipped = 0: skipLog = ""
    Set wsSrc = ActiveSheet

    '--- Resolve source columns --------------------------------------------
    cType = ReqCol(wsSrc, SRC_HEADER_ROW, H_TYPE, False, missing)
    cRin = ReqCol(wsSrc, SRC_HEADER_ROW, H_RIN, False, missing)
    cGrp = ReqCol(wsSrc, SRC_HEADER_ROW, H_GROUP, False, missing)
    cDept = ReqCol(wsSrc, SRC_HEADER_ROW, H_DEPT, False, missing)
    cCls = ReqCol(wsSrc, SRC_HEADER_ROW, H_CLASS, False, missing)
    cSub = ReqCol(wsSrc, SRC_HEADER_ROW, H_SUBCLASS, False, missing)
    cDesc = ReqCol(wsSrc, SRC_HEADER_ROW, H_DESC, False, missing)
    cMin = ReqCol(wsSrc, SRC_HEADER_ROW, H_MIN, False, missing)
    cMax = ReqCol(wsSrc, SRC_HEADER_ROW, H_MAX, False, missing)
    cRetail = ReqCol(wsSrc, SRC_HEADER_ROW, H_RETAIL, False, missing)
    cFee = ReqCol(wsSrc, SRC_HEADER_ROW, H_FEE, False, missing)
    cEff = ReqCol(wsSrc, SRC_HEADER_ROW, H_EFF, False, missing)
    cGtin = ReqCol(wsSrc, SRC_HEADER_ROW, H_GTIN, False, missing)
    If missing <> "" Then
        MsgBox "Could not find these headers on row " & SRC_HEADER_ROW & ":" & vbCrLf & missing, _
               vbExclamation, "Export TPGC"
        Exit Sub
    End If

    lastSrc = wsSrc.Cells(wsSrc.Rows.Count, cType).End(xlUp).Row
    If lastSrc <= SRC_HEADER_ROW Then
        MsgBox "No data found below row " & SRC_HEADER_ROW & ".", vbInformation, "Export TPGC"
        Exit Sub
    End If

    '--- Open target workbook ------------------------------------------------
    Set wbTgt = GetOrOpenWorkbook(TARGET_PATH)
    If wbTgt Is Nothing Then
        MsgBox "Could not open target workbook:" & vbCrLf & TARGET_PATH, vbCritical, "Export TPGC"
        Exit Sub
    End If

    Application.ScreenUpdating = False

    '--- TPGC_UPC ------------------------------------------------------------
    Set wsUPC = ReqSheet(wbTgt, TAB_UPC)
    missing = ""
    cUpcTran = ReqCol(wsUPC, TGT_HEADER_ROW, H_UPC_TRAN, False, missing)
    cUpcUpc = ReqCol(wsUPC, TGT_HEADER_ROW, H_UPC_UPC, False, missing)
    If missing <> "" Then Err.Raise vbObjectError + 2, , "Headers not found on '" & TAB_UPC & "':" & vbCrLf & missing
    ResolveDefaults wsUPC, UPC_DEFAULTS, upcDefCols, upcDefVals, False
    nextUPC = NextEmptyRow(wsUPC, cUpcTran)

    '--- TPGCNonMerchandise --------------------------------------------------
    Set wsNM = ReqSheet(wbTgt, TAB_NM)
    missing = ""
    cNmId = ReqCol(wsNM, TGT_HEADER_ROW, H_NM_ITEMID, True, missing)
    cNmName = ReqCol(wsNM, TGT_HEADER_ROW, H_NM_NAME, True, missing)
    cNmDesc = ReqCol(wsNM, TGT_HEADER_ROW, H_NM_DESC, True, missing)
    cNm1 = ReqCol(wsNM, TGT_HEADER_ROW, H_NM_M1, True, missing)
    cNm2 = ReqCol(wsNM, TGT_HEADER_ROW, H_NM_M2, True, missing)
    cNm3 = ReqCol(wsNM, TGT_HEADER_ROW, H_NM_M3, True, missing)
    cNm4 = ReqCol(wsNM, TGT_HEADER_ROW, H_NM_M4, True, missing)
    If missing <> "" Then Err.Raise vbObjectError + 2, , "Headers not found on '" & TAB_NM & "':" & vbCrLf & missing
    ResolveDefaults wsNM, NM_NOFEE_DEFAULTS, nmNoFeeCols, nmNoFeeVals, True
    ResolveDefaults wsNM, NM_FEE_DEFAULTS, nmFeeCols, nmFeeVals, True
    ResolveDefaults wsNM, NM_RANGE_NOFEE_DEFAULTS, nmRangeNoFeeCols, nmRangeNoFeeVals, True
    ResolveDefaults wsNM, NM_RANGE_FEE_DEFAULTS, nmRangeFeeCols, nmRangeFeeVals, True
    nextNM = NextEmptyRow(wsNM, cNmId)

    '--- ItemPriceAction -----------------------------------------------------
    Set wsPR = ReqSheet(wbTgt, TAB_PRICE)
    missing = ""
    cPrRin = ReqCol(wsPR, TGT_HEADER_ROW, H_PR_RIN, True, missing)
    cPrRetail = ReqCol(wsPR, TGT_HEADER_ROW, H_PR_RETAIL, True, missing)
    cPrEff = ReqCol(wsPR, TGT_HEADER_ROW, H_PR_EFF, True, missing)
    If missing <> "" Then Err.Raise vbObjectError + 2, , "Headers not found on '" & TAB_PRICE & "':" & vbCrLf & missing
    ResolveDefaults wsPR, PRICE_DEFAULTS, prDefCols, prDefVals, True
    nextPR = NextEmptyRow(wsPR, cPrRin)

    '--- TPGCAttachFee -------------------------------------------------------
    Set wsAF = ReqSheet(wbTgt, TAB_AF)
    missing = ""
    cAfSold = ReqCol(wsAF, TGT_HEADER_ROW, H_AF_SOLD, True, missing)
    cAfAtt = ReqCol(wsAF, TGT_HEADER_ROW, H_AF_ATTACHED, True, missing)
    cAfEff = ReqCol(wsAF, TGT_HEADER_ROW, H_AF_EFF, True, missing)
    If missing <> "" Then Err.Raise vbObjectError + 2, , "Headers not found on '" & TAB_AF & "':" & vbCrLf & missing
    ResolveDefaults wsAF, AF_DEFAULTS, afDefCols, afDefVals, True
    nextAF = NextEmptyRow(wsAF, cAfSold)

    '--- GCITMProperties -----------------------------------------------------
    Set wsGCP = ReqSheet(wbTgt, TAB_GCP)
    missing = ""
    cGcpId = ReqCol(wsGCP, TGT_HEADER_ROW, H_GCP_ITEMID, True, missing)
    cGcpProp = ReqCol(wsGCP, TGT_HEADER_ROW, H_GCP_PROP, True, missing)
    cGcpType = ReqCol(wsGCP, TGT_HEADER_ROW, H_GCP_TYPE, True, missing)
    cGcpDec = ReqCol(wsGCP, TGT_HEADER_ROW, H_GCP_DEC, True, missing)
    If missing <> "" Then Err.Raise vbObjectError + 2, , "Headers not found on '" & TAB_GCP & "':" & vbCrLf & missing
    ResolveDefaults wsGCP, GCP_DEFAULTS, gcpDefCols, gcpDefVals, True
    nextGCP = NextEmptyRow(wsGCP, cGcpId)

    '--- Route each source row -----------------------------------------------
    For r = SRC_HEADER_ROW + 1 To lastSrc
        giftType = Norm(CStr(wsSrc.Cells(r, cType).Value))
        If giftType <> "" Then
            Select Case giftType
                Case Norm("Fixed Price NoFee")
                    ExportFixedPrice r, False
                Case Norm("Fixed Price Fee")
                    ExportFixedPrice r, True
                Case Norm("Price Range No Fee")
                    ExportPriceRange r, False
                Case Norm("Price Range Fee")
                    ExportPriceRange r, True
                Case Else
                    nSkipped = nSkipped + 1
                    skipLog = skipLog & "  Row " & r & ": unhandled type '" & _
                              wsSrc.Cells(r, cType).Value & "'" & vbCrLf
            End Select
        End If
    Next r

    Application.ScreenUpdating = True
    wbTgt.Activate
    wsUPC.Activate

    summary = "Export complete." & vbCrLf & vbCrLf & _
              "Fixed Price NoFee: " & nNoFee & " row(s)" & vbCrLf & _
              "Fixed Price Fee: " & nFee & " row(s)" & vbCrLf & _
              "Price Range No Fee: " & nRangeNoFee & " row(s)" & vbCrLf & _
              "Price Range Fee: " & nRangeFee & " row(s)" & vbCrLf & _
              TAB_AF & ": " & nAF & " row(s)" & vbCrLf & _
              TAB_GCP & ": " & nGCP & " row(s)" & vbCrLf & _
              "Skipped: " & nSkipped & IIf(nSkipped > 0, vbCrLf & vbCrLf & Left$(skipLog, 800), "")

    If nNoFee + nFee + nRangeNoFee + nRangeFee = 0 Then
        MsgBox summary, vbExclamation, "Export TPGC"
        Exit Sub
    End If

    If MsgBox(summary & vbCrLf & vbCrLf & "Create the MNT file(s) now?", _
              vbYesNo + IIf(nSkipped > 0, vbExclamation, vbQuestion), "Export TPGC") = vbYes Then
        CreateMNTFiles wbTgt
    End If
    Exit Sub

Fail:
    Application.ScreenUpdating = True
    MsgBox "Export failed:" & vbCrLf & Err.Description, vbCritical, "Export TPGC"
End Sub

'==============================================================================
' Fixed Price (NoFee or Fee)
'==============================================================================
Private Sub ExportFixedPrice(ByVal r As Long, ByVal isFee As Boolean)
    Dim rin As String, upc11 As String, sRetail As String, sEff As String
    Dim problem As String, fees As Collection, fee As Variant

    rin = Trim$(CStr(wsSrc.Cells(r, cRin).Value))
    upc11 = UPCFirst11(wsSrc.Cells(r, cGtin).Value)
    sRetail = RetailText(wsSrc.Cells(r, cRetail).Value)
    sEff = DateText(wsSrc.Cells(r, cEff).Value)
    If isFee Then Set fees = ParseList(wsSrc.Cells(r, cFee).Value)

    If rin = "" Then problem = problem & "RIN#, "
    If upc11 = "" Then problem = problem & "GTIN/UPC#, "
    If sRetail = "" Then problem = problem & "Fixed Retail, "
    If sEff = "" Then problem = problem & "Effective Date, "
    If isFee Then
        If fees.Count = 0 Then problem = problem & "Fee RIN, "
    End If
    If problem <> "" Then LogSkip r, problem: Exit Sub

    WriteUPC r, upc11
    If isFee Then
        WriteNonMerch r, nmFeeCols, nmFeeVals
    Else
        WriteNonMerch r, nmNoFeeCols, nmNoFeeVals
    End If

    '--- ItemPriceAction ---
    WriteDefaults wsPR, nextPR, prDefCols, prDefVals
    wsPR.Cells(nextPR, cPrRin).Value = wsSrc.Cells(r, cRin).Value
    wsPR.Cells(nextPR, cPrRetail).NumberFormat = "@"
    wsPR.Cells(nextPR, cPrRetail).Value = sRetail
    wsPR.Cells(nextPR, cPrEff).NumberFormat = "@"
    wsPR.Cells(nextPR, cPrEff).Value = sEff
    nextPR = nextPR + 1

    '--- TPGCAttachFee (Fee only; one row per fee RIN) ---
    If isFee Then
        For Each fee In fees
            WriteAttachFee r, CStr(fee), sEff
        Next fee
        nFee = nFee + 1
    Else
        nNoFee = nNoFee + 1
    End If
End Sub

'==============================================================================
' Price Range (NoFee or Fee)
'==============================================================================
Private Sub ExportPriceRange(ByVal r As Long, ByVal isFee As Boolean)
    Dim rin As String, upc11 As String, sEff As String, problem As String
    Dim vMin As Variant, vMax As Variant, fees As Collection, fee As Variant

    rin = Trim$(CStr(wsSrc.Cells(r, cRin).Value))
    upc11 = UPCFirst11(wsSrc.Cells(r, cGtin).Value)
    vMin = NumValue(wsSrc.Cells(r, cMin).Value)
    vMax = NumValue(wsSrc.Cells(r, cMax).Value)
    If isFee Then
        sEff = DateText(wsSrc.Cells(r, cEff).Value)
        Set fees = ParseList(wsSrc.Cells(r, cFee).Value)
    End If

    If rin = "" Then problem = problem & "RIN#, "
    If upc11 = "" Then problem = problem & "GTIN/UPC#, "
    If IsEmpty(vMin) Then problem = problem & "Price Range (Min), "
    If IsEmpty(vMax) Then problem = problem & "Price Range (Max), "
    If Not IsEmpty(vMin) And Not IsEmpty(vMax) Then
        If vMin > vMax Then problem = problem & "Min greater than Max, "
    End If
    If isFee Then
        If sEff = "" Then problem = problem & "Effective Date, "
        If fees.Count = 0 Then problem = problem & "Fee RIN, "
    End If
    If problem <> "" Then LogSkip r, problem: Exit Sub

    WriteUPC r, upc11
    If isFee Then
        WriteNonMerch r, nmRangeFeeCols, nmRangeFeeVals
    Else
        WriteNonMerch r, nmRangeNoFeeCols, nmRangeNoFeeVals
    End If

    WriteItemProperty r, GCP_PROP_MIN, vMin
    WriteItemProperty r, GCP_PROP_MAX, vMax

    If isFee Then
        For Each fee In fees
            WriteAttachFee r, CStr(fee), sEff
        Next fee
        nRangeFee = nRangeFee + 1
    Else
        nRangeNoFee = nRangeNoFee + 1
    End If
End Sub

'==============================================================================
' Tab writers
'==============================================================================
Private Sub WriteUPC(ByVal r As Long, ByVal upc11 As String)
    WriteDefaults wsUPC, nextUPC, upcDefCols, upcDefVals
    wsUPC.Cells(nextUPC, cUpcTran).Value = wsSrc.Cells(r, cRin).Value
    wsUPC.Cells(nextUPC, cUpcUpc).NumberFormat = "@"   ' keep leading zeros
    wsUPC.Cells(nextUPC, cUpcUpc).Value = upc11
    nextUPC = nextUPC + 1
End Sub

Private Sub WriteNonMerch(ByVal r As Long, cols() As Long, vals() As String)
    Dim sGrp As String, sDept As String, sCls As String, sSub As String
    sGrp = Trim$(CStr(wsSrc.Cells(r, cGrp).Value))
    sDept = Trim$(CStr(wsSrc.Cells(r, cDept).Value))
    sCls = Trim$(CStr(wsSrc.Cells(r, cCls).Value))
    sSub = Trim$(CStr(wsSrc.Cells(r, cSub).Value))

    WriteDefaults wsNM, nextNM, cols, vals
    wsNM.Cells(nextNM, cNmId).Value = wsSrc.Cells(r, cRin).Value
    wsNM.Cells(nextNM, cNmName).Value = wsSrc.Cells(r, cDesc).Value
    wsNM.Cells(nextNM, cNmDesc).Value = wsSrc.Cells(r, cDesc).Value
    wsNM.Cells(nextNM, cNm1).Value = sGrp & "G"
    wsNM.Cells(nextNM, cNm2).Value = sDept & "D"
    wsNM.Cells(nextNM, cNm3).Value = sDept & "-" & sCls & "C"
    wsNM.Cells(nextNM, cNm4).Value = sDept & "-" & sCls & "-" & sSub & "S"
    nextNM = nextNM + 1
End Sub

Private Sub WriteAttachFee(ByVal r As Long, ByVal feeRin As String, ByVal sEff As String)
    WriteDefaults wsAF, nextAF, afDefCols, afDefVals
    wsAF.Cells(nextAF, cAfSold).Value = wsSrc.Cells(r, cRin).Value
    wsAF.Cells(nextAF, cAfAtt).Value = feeRin
    wsAF.Cells(nextAF, cAfEff).NumberFormat = "@"
    wsAF.Cells(nextAF, cAfEff).Value = sEff
    nextAF = nextAF + 1
    nAF = nAF + 1
End Sub

Private Sub WriteItemProperty(ByVal r As Long, ByVal propCode As String, ByVal amount As Variant)
    WriteDefaults wsGCP, nextGCP, gcpDefCols, gcpDefVals
    wsGCP.Cells(nextGCP, cGcpId).Value = wsSrc.Cells(r, cRin).Value
    wsGCP.Cells(nextGCP, cGcpProp).Value = propCode
    wsGCP.Cells(nextGCP, cGcpType).Value = GCP_TYPE_VALUE
    wsGCP.Cells(nextGCP, cGcpDec).Value = amount
    nextGCP = nextGCP + 1
    nGCP = nGCP + 1
End Sub

Private Sub LogSkip(ByVal r As Long, ByVal problem As String)
    nSkipped = nSkipped + 1
    skipLog = skipLog & "  Row " & r & ": missing/invalid " & Left$(problem, Len(problem) - 2) & vbCrLf
End Sub

' Builds one MNT file per populated TPGC tab in a folder the user picks.
Private Sub CreateMNTFiles(wb As Workbook)
    Dim tabs As Variant, i As Long, ws As Worksheet
    Dim lastRow() As Long, lastCol() As Long, useTab() As Boolean
    Dim msg As String, folder As String, stamp As String
    Dim outPath As String, created As String, nFiles As Long

    On Error GoTo Fail
    tabs = Array(TAB_UPC, TAB_NM, TAB_PRICE, TAB_AF, TAB_GCP)
    ReDim lastRow(LBound(tabs) To UBound(tabs))
    ReDim lastCol(LBound(tabs) To UBound(tabs))
    ReDim useTab(LBound(tabs) To UBound(tabs))

    '--- Find populated tabs and their data extents ---
    For i = LBound(tabs) To UBound(tabs)
        Set ws = GetSheet(wb, CStr(tabs(i)))
        If Not ws Is Nothing Then
            lastRow(i) = LastUsedRow(ws)
            lastCol(i) = LastUsedCol(ws)
            If lastRow(i) >= TGT_FIRST_DATA_ROW And lastCol(i) > 0 Then
                useTab(i) = True
                msg = msg & ws.Name & ": " & (lastRow(i) - 1) & " row(s)" & vbCrLf & _
                      "    Last col " & ColLetter(ws, lastCol(i)) & " """ & _
                      ShortHeader(ws.Cells(TGT_HEADER_ROW, lastCol(i)).Value) & """" & vbCrLf & _
                      "    Last cell: """ & cellText(ws.Cells(lastRow(i), lastCol(i))) & """" & vbCrLf
            End If
        End If
    Next i

    If msg = "" Then
        MsgBox "None of the TPGC tabs have data below the header row.", vbInformation, "Create MNT"
        Exit Sub
    End If

    '--- Sanity check (catches hidden old data, as in Start_MNT) ---
    If MsgBox("Create MNT files for these tabs?" & vbCrLf & vbCrLf & msg & vbCrLf & _
              "If a row count or last column looks wrong, click No. There may be old or " & _
              "hidden data - delete all rows under the last row and columns to the right.", _
              vbYesNo + vbQuestion, "Check the data") = vbNo Then
        MsgBox "MNT creation aborted.", vbInformation, "Create MNT"
        Exit Sub
    End If

    '--- Ask where to save ---
    folder = PickFolder()
    If folder = "" Then
        MsgBox "No folder selected. MNT creation cancelled.", vbInformation, "Create MNT"
        Exit Sub
    End If

    '--- Write files ---
    stamp = Format$(Now(), "yyyy_mm_dd_hhmm")
    For i = LBound(tabs) To UBound(tabs)
        If useTab(i) Then
            Set ws = GetSheet(wb, CStr(tabs(i)))
            outPath = folder & "\MNTCreation_" & ws.Name & "-" & Environ("Username") & stamp & ".mnt"
            WriteMNT ws, lastRow(i), lastCol(i), outPath
            created = created & "  " & Mid$(outPath, InStrRev(outPath, "\") + 1) & vbCrLf
            nFiles = nFiles + 1
        End If
    Next i

    MsgBox "Created " & nFiles & " MNT file(s) in:" & vbCrLf & folder & vbCrLf & vbCrLf & created, _
           vbInformation, "Create MNT"
    Exit Sub

Fail:
    Close
    MsgBox "MNT creation failed:" & vbCrLf & Err.Description, vbCritical, "Create MNT"
End Sub

' Same output as Normal_MNT: rows 2..lastRow, columns 1..lastCol joined by "|",
' followed by one blank line.
Private Sub WriteMNT(ws As Worksheet, ByVal lastRow As Long, ByVal lastCol As Long, ByVal outPath As String)
    Dim f As Integer, r As Long, c As Long, oLine As String
    f = FreeFile
    Open outPath For Output As #f
    For r = TGT_FIRST_DATA_ROW To lastRow
        oLine = ""
        For c = 1 To lastCol
            If c > 1 Then oLine = oLine & "|"
            oLine = oLine & cellText(ws.Cells(r, c))
        Next c
        Print #f, oLine
    Next r
    Print #f, ""
    Close #f
End Sub

' Folder picker; returns "" if cancelled.
Private Function PickFolder() As String
    With Application.FileDialog(msoFileDialogFolderPicker)
        .Title = "Choose where to save the MNT file(s)"
        .AllowMultiSelect = False
        If .Show = -1 Then
            PickFolder = .SelectedItems(1)
            If Right$(PickFolder, 1) = "\" Then PickFolder = Left$(PickFolder, Len(PickFolder) - 1)
        End If
    End With
End Function

' Last row containing anything (including hidden rows).
Private Function LastUsedRow(ws As Worksheet) As Long
    Dim f As Range
    Set f = ws.Cells.Find(What:="*", LookIn:=xlFormulas, SearchOrder:=xlByRows, _
                          SearchDirection:=xlPrevious)
    If Not f Is Nothing Then LastUsedRow = f.Row
End Function

' Last column containing anything (including the header row and hidden columns).
Private Function LastUsedCol(ws As Worksheet) As Long
    Dim f As Range
    Set f = ws.Cells.Find(What:="*", LookIn:=xlFormulas, SearchOrder:=xlByColumns, _
                          SearchDirection:=xlPrevious)
    If Not f Is Nothing Then LastUsedCol = f.Column
End Function

' Cell value as text, the same way Normal_MNT concatenates it; errors become "".
Private Function cellText(c As Range) As String
    If IsError(c.Value) Then Exit Function
    cellText = c.Value
End Function

Private Function ColLetter(ws As Worksheet, ByVal col As Long) As String
    ColLetter = Split(ws.Cells(1, col).Address, "$")(1)
End Function

' First line of a header, trimmed to 40 characters for display.
Private Function ShortHeader(ByVal v As Variant) As String
    Dim s As String
    If IsError(v) Then Exit Function
    s = Replace(CStr(v), vbCr, vbLf)
    If InStr(s, vbLf) > 0 Then s = Left$(s, InStr(s, vbLf) - 1)
    s = Trim$(s)
    If Len(s) > 40 Then s = Left$(s, 37) & "..."
    ShortHeader = s
End Function

'==============================================================================
' Helpers
'==============================================================================

' FindHeader that appends the header to 'missing' when not found.
Private Function ReqCol(ws As Worksheet, hdrRow As Long, headerText As String, _
                        matchPrefix As Boolean, ByRef missing As String) As Long
    ReqCol = FindHeader(ws, hdrRow, headerText, matchPrefix)
    If ReqCol = 0 Then missing = missing & "  - " & headerText & vbCrLf
End Function

' Returns the named sheet or raises an error.
Private Function ReqSheet(wb As Workbook, sheetName As String) As Worksheet
    Set ReqSheet = GetSheet(wb, sheetName)
    If ReqSheet Is Nothing Then Err.Raise vbObjectError + 1, , _
        "Tab '" & sheetName & "' not found in target workbook."
End Function

' Parses "Header|Value~Header|Value" and resolves each header to its column.
' Raises an error listing any headers not found on the tab.
Private Sub ResolveDefaults(ws As Worksheet, spec As String, cols() As Long, vals() As String, _
                            matchPrefix As Boolean)
    Dim pairs() As String, parts() As String, i As Long, missing As String
    pairs = Split(spec, "~")
    ReDim cols(LBound(pairs) To UBound(pairs))
    ReDim vals(LBound(pairs) To UBound(pairs))
    For i = LBound(pairs) To UBound(pairs)
        parts = Split(pairs(i), "|")
        cols(i) = FindHeader(ws, TGT_HEADER_ROW, parts(0), matchPrefix)
        vals(i) = parts(1)
        If cols(i) = 0 Then missing = missing & "  - " & parts(0) & vbCrLf
    Next i
    If missing <> "" Then Err.Raise vbObjectError + 3, , _
        "Default-value headers not found on '" & ws.Name & "':" & vbCrLf & missing
End Sub

' Writes the default values into one row.
Private Sub WriteDefaults(ws As Worksheet, rowNum As Long, cols() As Long, vals() As String)
    Dim i As Long
    For i = LBound(cols) To UBound(cols)
        ws.Cells(rowNum, cols(i)).Value = vals(i)
    Next i
End Sub

' Returns the column of a header on the given row, or 0 if not found.
' Comparison ignores case and all whitespace. matchPrefix = True matches headers
' that START with headerText (for long multi-line headers).
Private Function FindHeader(ws As Worksheet, hdrRow As Long, headerText As String, _
                            Optional matchPrefix As Boolean = False) As Long
    Dim lastCol As Long, c As Long, target As String, cellText As String
    target = Tight(headerText)
    lastCol = ws.Cells(hdrRow, ws.Columns.Count).End(xlToLeft).Column
    For c = 1 To lastCol
        cellText = Tight(CStr(ws.Cells(hdrRow, c).Value))
        If matchPrefix Then
            If Left$(cellText, Len(target)) = target Then FindHeader = c: Exit Function
        Else
            If cellText = target Then FindHeader = c: Exit Function
        End If
    Next c
End Function

' Extracts fee RINs from a cell. Ignores anything in parentheses (e.g. the fee
' amount in "14243675 (3.95)") and keeps only all-digit values, so a cell can
' hold one or more RINs separated by commas, semicolons, slashes, spaces or
' line breaks.
Private Function ParseList(ByVal v As Variant) As Collection
    Dim s As String, clean As String, ch As String
    Dim parts() As String, i As Long, depth As Long, tok As String
    Set ParseList = New Collection
    If IsEmpty(v) Then Exit Function
    If IsNumeric(v) Then
        s = Format$(CDec(v), "0")
    Else
        s = CStr(v)
    End If

    ' Drop anything inside parentheses
    For i = 1 To Len(s)
        ch = Mid$(s, i, 1)
        If ch = "(" Then
            depth = depth + 1
        ElseIf ch = ")" Then
            If depth > 0 Then depth = depth - 1
        ElseIf depth = 0 Then
            clean = clean & ch
        End If
    Next i

    clean = Replace(clean, vbCr, " ")
    clean = Replace(clean, vbLf, " ")
    clean = Replace(clean, ",", " ")
    clean = Replace(clean, ";", " ")
    clean = Replace(clean, "/", " ")
    clean = Replace(clean, Chr(160), " ")
    parts = Split(Application.WorksheetFunction.Trim(clean), " ")

    ' Keep digit-only tokens (RINs)
    For i = LBound(parts) To UBound(parts)
        tok = Trim$(parts(i))
        If tok <> "" Then
            If Not tok Like "*[!0-9]*" Then ParseList.Add tok
        End If
    Next i
End Function

' Uppercase, trimmed, internal whitespace/line breaks collapsed to single spaces.
Private Function Norm(ByVal s As String) As String
    s = Replace(s, vbCr, " ")
    s = Replace(s, vbLf, " ")
    s = Replace(s, vbTab, " ")
    s = Replace(s, Chr(160), " ")
    s = Trim$(s)
    Do While InStr(s, "  ") > 0
        s = Replace(s, "  ", " ")
    Loop
    Norm = UCase$(s)
End Function

' Norm with all spaces removed.
Private Function Tight(ByVal s As String) As String
    Tight = Replace(Norm(s), " ", "")
End Function

' Numeric value of a cell ($ and commas allowed); Empty if blank or not numeric.
Private Function NumValue(ByVal v As Variant) As Variant
    Dim s As String
    s = Replace(Replace(Trim$(CStr(v)), "$", ""), ",", "")
    If s = "" Then Exit Function
    If Not IsNumeric(s) Then Exit Function
    NumValue = CDbl(s)
End Function

' Retail as "0.00" text; "" if blank or not numeric.
Private Function RetailText(ByVal v As Variant) As String
    Dim n As Variant
    n = NumValue(v)
    If IsEmpty(n) Then Exit Function
    RetailText = Format$(n, "0.00")
End Function

' Date as "yyyy-mm-dd" text; "" if blank or not a date.
Private Function DateText(ByVal v As Variant) As String
    If IsEmpty(v) Then Exit Function
    If Trim$(CStr(v)) = "" Then Exit Function
    If Not IsDate(v) Then Exit Function
    DateText = Format$(CDate(v), "yyyy-mm-dd")
End Function

' Digits only; normalizes to a 12-digit UPC-A (pads lost leading zeros,
' drops extra leading zeros from GTIN-13/14), then returns the first 11 digits.
Private Function UPCFirst11(ByVal v As Variant) As String
    Dim s As String, d As String, i As Long, ch As String
    If IsNumeric(v) And Not IsEmpty(v) Then
        s = Format$(CDec(v), "0")
    Else
        s = CStr(v)
    End If
    For i = 1 To Len(s)
        ch = Mid$(s, i, 1)
        If ch Like "#" Then d = d & ch
    Next i
    If d = "" Then Exit Function
    Do While Len(d) > 12 And Left$(d, 1) = "0"
        d = Mid$(d, 2)
    Loop
    If Len(d) < 12 Then d = String$(12 - Len(d), "0") & d
    UPCFirst11 = Left$(d, 11)
End Function

    Dim r As Long
    r = ws.Cells(ws.Rows.Count, keyCol).End(xlUp).Row + 1
    If r < TGT_FIRST_DATA_ROW Then r = TGT_FIRST_DATA_ROW
    NextEmptyRow = r

Creating the Needed MNT Files

💡
Faster option: the TPGC Cheat Sheet fills these tabs and creates the MNT files for you. The manual steps below are still useful for one-off fixes.

An MNT file is a simple pipe-delimited file used to import specific data into Xadmin's data tables. The data is entered in the MNT Creator Excel workbook, and a built-in macro (Ctrl+Shift+M) converts the active tab into an .mnt file.

  1. Get the latest MNT Creator workbook: download the 2026_01 Master Creator, or email the ORUP team for the current location of the most up-to-date file.
  2. Open the file and do a File → Save As to a location of your choosing. Fill in only the tabs you need converted (see the table above).
  3. A pop-up appears as a reminder of the keystrokes used to convert each tab. Select OK.
  4. Navigate to the tab(s) needed for the type of TPGC you are building.
  5. Enter the data on the tab, then clear any rows below the last row of entered data.
  6. With that tab active, press Ctrl+Shift+M. The file created is based on the tab that is currently active.
  7. A Check the data prompt shows the last column header, last row count and last cell value. Select Yes after verifying it is correct.
  8. If the converter works, a Done window appears. Select OK.
  9. The .mnt file is saved to your U drive. The file name is generated automatically from the tab name, your name, the date and a reference number.
  10. Repeat for each tab the card type needs. Each tab creates its own .mnt file.
⚠
Check the U drive first. If there is a red X on the U drive in File Explorer, the file will not convert. Click the drive to reconnect it, then go back to the workbook and create the MNT file again.
